## 各论文局限

| 论文 | 局限 |
|------|------|
| P1 | 材料体系（WBGS）与项目器件（2D 材料）不同；不能将参数移植 |
| P2 | 单器件水平；无 D2D 数据；CNN 在软件中；成像用 XY 扫描 |
| P3 | 单器件；感知机仿真仅在 MATLAB；需要外加光感器件 |
| P4 | 全 Xilinx 工具链，Altera 需架构调整；MNIST 级别 SNN 无优势 |
| P5 | 存在多处方法学缺陷（层数矛盾、激活函数错误、GPU 对比不当） |
| P6 | 有机忆阻 vs 光学 GDY/WSe₂；所有元件选型是实例 |
| P7 | SFG 双栅结构不同；无 FPGA 集成；依赖台面仪器 |
