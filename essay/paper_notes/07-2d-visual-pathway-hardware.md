# 论文笔记 07：二维材料视觉通路硬件（含 ESM）

## 论文信息

- **标题**：Multifunctional human visual pathway-replicated hardware based on 2D materials
- **作者**：Zhuiri Peng, Lei Tong 等（华中科技大学 + 香港中文大学 + 国防科技大学）
- **期刊**：Nature Communications 15, 8650 (2024)
- **论文编号**：P7
- **证据等级**：B（外部阵列系统参考）

## 纳入原因

1. 10×10 WSe₂ SFG 阵列——小阵列做光学卷积和 VMM 的模板
2. 阵列作为特征提取器（3×3/5×5 卷积核）
3. 稀疏神经网络减少权重数
4. 光学掩模 + 逐点扫描 + TIA 读出

## 核心内容

### 器件和阵列
- 10×10 WSe₂ 分栅浮栅（SFG）交叉阵列
- 双模式：光伏二极管（光模式）和双极晶体管（电模式）
- 双栅极 VG1/VG2 独立调制正/负光响应

### 功能
1. **颜色处理**：CSRF 卷积 → RGB 颜色通路 → Daltonism 模拟
2. **形状识别**：双曲稀疏神经网络 5×8×4，>95%
3. **运动跟踪**：Barlow-Levick 延时模型

### 关键数据
- 编程能耗：<1 pJ/spike
- 稀疏 NN：28 vs 72 器件（61.1% 减少）
- 编程能量：0.9 nJ/操作

## 可复用设计
- 小阵列做光学卷积/特征提取
- 稀疏神经网络减少资源需求
- TIA → ADC → 数字处理链

## 不可移植
- **SFG 双栅结构 ≠ 项目两端器件**
- 正/负光响应是 SFG 特定能力
- 10×10 WSe₂ 阵列的工艺和材料不同
- 实验依赖源表/探针台，非 FPGA 集成

## 与 4×4 关系
- 4×4 作为特征提取器的路线参考
- 稀疏神经网络概念用于 FPGA 资源优化
