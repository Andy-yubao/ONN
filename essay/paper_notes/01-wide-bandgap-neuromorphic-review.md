# 论文笔记 01：宽禁带半导体类脑计算综述

## 论文信息

- **标题**：Wide-Bandgap Semiconductor-Based Neuromorphic Computing
- **作者**：Hongyu Tang, Pengsheng Min, Yang Zhang 等（复旦大学 + Delft University of Technology）
- **类型**：综述论文
- **论文编号**：P1
- **证据等级**：A（课题组论文——共享通讯作者、提供评价框架）

## 纳入原因

1. 提供神经形态器件的统一评价指标框架
2. 与 P2 共享通讯作者（唐鸿雨），反映课题组对器件方向的整体认识
3. 覆盖的器件类型（忆阻器/突触晶体管/神经元器件）和机制（阻变/电荷捕获/极化调制）为理解 P2 提供背景

## 核心内容

### 覆盖材料
- III 族氮化物：GaN (3.4 eV), AlN (6.2 eV), h-BN (5.8 eV)
- SiC (3C/4H/6H, 2.2–3.26 eV)
- Ga₂O₃ (4.2–4.9 eV, 超宽禁带)
- Diamond (5.5 eV, 超宽禁带)

### 器件类型
1. **电子忆阻器**：ECM/VCM/TCM 机制，MIM 结构
2. **光电忆阻器**：GaN/AlN、SiC/SiO₂@Ag NW、Ga₂O₃ UV
3. **铁电器件**：AlScN, ScAlN/GaN
4. **突触晶体管**：GaN HEMT，电解质门控 Ga₂O₃，浮栅 WSe₂/h-BN
5. **神经元器件**：AlN 阈值开关（LIF 神经元，~50 ns）

### 评价指标
- ON/OFF 比、耐久、保持、能耗、开关速度
- 线性度、对称性、动态范围、D2D/C2C 变异
- 噪声容忍度、温度稳定性

## 关键结果
- 全面的材料-器件-系统三级综述
- 指出"缺陷设计"（defect-by-design）策略
- 强调标准化评估的必要性

## 可复用内容
- 神经形态器件的评价指标框架
- 器件分类和比较方法

## 不可移植参数
- WBGS 的材料参数、开关电压、集成方案
- GaN/SiC 的成熟 CMOS 兼容性不能假设

## 方法学局限
- 综述性质，不提供新的实验数据
- WBGS 与 2D 材料（如 WSe₂）在材料体系上不同

## 与 4×4 项目的关系
- 提供指标框架用于评估器件
- 不提供项目器件的直接参数
