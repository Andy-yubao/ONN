## 证据等级说明

| 等级 | 含义 | 用途限制 |
|------|------|---------|
| **A** | 课题组论文，直接相关 | 项目能力主要证据，注意单器件 vs 阵列、论文条件 vs 当前条件 |
| **B** | 外部论文，器件或系统级参考 | 可借鉴架构和思路，**参数不可移植** |
| **C** | 外部论文，算法或部署参考 | 可借鉴方法和流程，**受平台和假设条件限制** |

## 阅读顺序（按双主线框架）

1. **阅读 `docs/project_scope.md`** —— 先理解双主线范围
2. **主线 A 相关**：
   - P2（课题组器件论文）—— 了解器件能力和光响应特性
   - P6（有机 32×32 系统）—— 了解信号链和阵列架构参考
   - P7（2D 视觉通路）—— 了解小阵列用法参考
3. **主线 B 相关**：
   - P4（CNN/SNN FPGA 比较）—— 了解定点 CNN 部署架构
   - P5（FPGA ANN 示例）—— 了解训练到部署基本流程（批判性阅读）
   - P7（2D 视觉通路）—— 了解光学卷积方法（非直接使用）
4. **主线 C 相关**：
   - P3（外部光学神经突触）—— 详细了解差分权重和参数映射方法
   - P2（课题组器件论文）—— 了解光响应曲线和时序编码
   - P1（综述）—— 了解器件评价指标
