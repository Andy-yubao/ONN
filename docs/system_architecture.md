# 系统架构

> **当前状态**：M0 已完成。架构按两条独立路线组织。两张架构图之间当前无强制实时数据接口。

---

## 路线 A：光电突触阵列信号采集与光功率重建

### 架构图

```
固定波长激光输入
       ↓
4×4 光电突触阵列
       ↓
偏置与电流读出（可控/可配置偏置）
       ↓
模拟信号调理（电流 → ADC 可采电压）
       ↓
ADC
       ↓
┌─────────────────────────────────────┐
│ FPGA 采样、缓存和控制               │
│  ├─ 可配置采样参数                   │
│  │   (sample_period, start_delay,    │
│  │    sample_count, average_count)   │
│  ├─ 表征模式 / 稳态测量模式          │
│  └─ 原始 ADC 数据保留/导出          │
├─────────────────────────────────────┤
│ FPGA 校正与归一化                    │
│  ├─ 零点/增益校正                    │
│  └─ 响应归一化                      │
├─────────────────────────────────────┤
│ FPGA 光功率映射                      │
│  ├─ LUT / 分段线性插值               │
│  └─ 定点多项式（无浮点指数/对数）    │
└─────────────────────────────────────┘
       ↓
4×4 光功率矩阵
       ↓
数据传输或显示
```

### 设计原则

| 原则 | 说明 |
|------|------|
| 需要偏置 | 零偏置读取不够稳定，工程基线采用可控配置偏置；偏置值待实验确定 |
| 离线标定 | PC 端拟合模型参数，FPGA 只使用已标定参数完成在线计算 |
| 不锁定具体型号 | TIA/ADC/运放的具体型号待器件参数确认后选择 |
| 配置优先 | 采样参数可配置，第一版实现两种基本工作方式（表征/稳态），不追求全功能瞬态捕获 |
| 原始数据保留 | ADC 原始码、校正值、归一化值、光功率估计值都是有效数据输出 |
| 安全优先 | 所有电路设计以安全读出为第一原则 |

### FPGA 在路线 A 中的职责

- ADC 采样控制
- 数据缓存
- 原始值校正（零点/增益）
- 响应归一化
- 使用已标定模型估计光功率（LUT/分段线性/定点多项式）
- 输出 4×4 光功率矩阵
- 原始 ADC 数据导出

> FPGA **不**负责在线重新拟合模型参数。

## 路线 B：类脑 CNN 训练研究与 FPGA 推理部署

### 架构图

```
MNIST 28×28 单通道灰度图
       ↓
┌──────────────────────────────────────┐
│ PC 端：标准反向传播训练基线          │
│  ├─ Tiny-ResNet / 浅层残差 CNN       │
│  └─ 普通 CNN / LeNet 对照            │
├──────────────────────────────────────┤
│ PC 端：类脑更新规则实验              │
│  ├─ Hebbian / Oja 变体 / 三因素规则  │
│  ├─ 活动依赖增强/衰减                │
│  └─ 混合规则 / Hebbian 预训练+微调   │
├──────────────────────────────────────┤
│ PC 端：量化和参数导出                │
│  ├─ 定点/量化方案（位宽待定）        │
│  └─ 权重/偏置/测试向量导出           │
└──────────────────────────────────────┘
       ↓
┌──────────────────────────────────────┐
│ FPGA：定点 CNN 前向推理              │
│  ├─ 输入适配                         │
│  ├─ 卷积/MAC 运算                    │
│  ├─ 激活函数                         │
│  ├─ 池化（如需）                     │
│  ├─ 全连接层                         │
│  └─ argmax → 分类结果                │
└──────────────────────────────────────┘
       ↓
分类结果（0–9）和性能数据
```

### 设计原则

| 原则 | 说明 |
|------|------|
| 纯数字推理 | FPGA 执行标准定点 CNN 前向计算，不涉及物理器件 |
| 训练完全离线 | 所有训练在 PC 端完成，FPGA 不执行在线训练或权重更新 |
| 独立输入 | 输入为 MNIST 数字图像，不来自路线 A 的采集电路 |
| 基线优先 | 先建立标准反向传播基线，再探索类脑规则 |
| Cyclone IV E 约束 | 资源有限（EP4CE10 ~10K LE），网络设计受此约束 |
| 28×28 ≠ 4×4 | 路线 B 输入与路线 A 输出尺寸不同，但不构成矛盾——二者为独立路线 |

### FPGA 在路线 B 中的职责

- 加载定点权重和偏置
- 执行定点 CNN 前向推理
- 输出分类结果
- 提供资源占用和时序报告

> FPGA **不**读取器件曲线、不模拟物理演化、不执行在线训练。

## 两条路线的关系

```
路线 A：4×4 光功率矩阵
       ↕ 研究主题相关，当前无强制实时数据接口
路线 B：28×28 MNIST CNN 推理
```

| 方面 | 路线 A | 路线 B |
|------|--------|--------|
| 输入 | 固定波长激光 → 4×4 阵列 | MNIST 28×28 灰度图 |
| 输出 | 4×4 光功率矩阵 | 0–9 分类结果 |
| FPGA 角色 | 采样控制、校正、归一化、光功率映射 | CNN 前向推理 |
| 模拟电路 | 需要（偏置/读出/调理/ADC） | 不需要（纯数字） |
| 训练 | 离线标定（PC 端拟合模型） | 离线训练（PC 端） |
| 器件依赖 | 直接依赖 | 不依赖 |

---

## 当前不做

- 路线 A → 路线 B 硬件连接或联调
- RGB 三通道输入
- CNN 处理 4×4 时间序列
- FPGA 在线训练或权重更新
- 阵列内 VMM / 模拟计算
- SNN / 储备池计算
- 端到端光电识别系统
- Vivado / FINN / PYNQ 工具链
