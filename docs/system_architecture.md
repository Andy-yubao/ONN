# 系统架构

> **当前状态**：M0 阶段。架构按两条独立主线组织，外加一条离线辅助关系。本文档描述当前设计范围，**不预设未确认的具体型号或数值**。

---

## 架构 A：4×4 外围采集系统

### 数据流

```
受控光源/光脉冲
  → 4×4 光学突触阵列
    → 保护、偏置与通道选择
      → 电流/电压读出及模拟调理
        → 模数转换 (ADC)
          → 采集控制器 / 数据传输
            → PC 原始数据保存、标定与曲线分析
```

### 设计原则

| 原则 | 说明 |
|------|------|
| **传感器读出** | 电路用于器件表征和数据采集，不是计算阵列外围 |
| **不预设控制器** | 采集控制器可以是 FPGA、MCU 或 PC 直接采集，根据实际需求选择 |
| **不预设并行度** | 不预设 16 路同时采样，通道数由 ADC 通道数、MUX 配置和采样率需求共同决定 |
| **不预设输出形式** | 采集数据首先为 ADC 原始码，标定后为电压/电流，电导为派生量（条件满足时换算） |
| **不预设具体型号** | 不预设 TIA/MUX/ADC 具体型号，选型在器件参数确认后进行 |
| **安全优先** | 所有电路设计以安全读出为第一原则 |

### 三种逻辑采样模式

| 模式 | 典型用途 | 采样特征 |
|------|---------|---------|
| **快速瞬态模式** | 光照开关、短脉冲、峰值、上升下降沿捕获 | 最高采样率，短记录窗口 |
| **常规曲线模式** | 一般响应曲线、重复刺激、稳态测量 | 中等采样率，完整记录响应过程 |
| **长时监测模式** | 衰减、保持、恢复、漂移观察 | 低速连续记录，长时间运行 |

> 具体采样率数值由器件最快有效响应、模拟带宽、MUX 建立时间、ADC 吞吐率和数据传输能力派生。**未经论证不得写死**。

### 单通道有效采样率

若使用单 ADC + 多路 MUX 实现多通道：

```
单通道有效采样率 ≈ ADC 总有效采样率 / 通道数
```

还需考虑：MUX 建立时间、放大器建立时间、ADC 采样保持、丢弃首样、控制和传输开销。

## 架构 B：28×28 CNN FPGA 数字推理

### 数据流

```
MNIST / 测试图像
  → Python 浮点 CNN 训练
    → 量化与 bit-accurate 参考模型
      → 参数和测试向量导出
        → FPGA 输入缓存
          → 定点 CNN 前向推理
            → 分类和调试输出
```

### 设计原则

| 原则 | 说明 |
|------|------|
| **纯数字推理** | FPGA 执行标准数字定点 CNN 前向计算，不使用物理器件参与乘加 |
| **独立输入** | 输入来自数字数据源（testbench / ROM / PC 传输），不来自 4×4 采集电路 |
| **28×28 与 4×4 无直接映射** | 二者尺寸不同，但不构成矛盾——因为不是同一主线的输入输出关系 |
| **FPGA 不执行训练** | 训练在 Python 端完成，FPGA 只部署前向推理 |
| **FPGA 不读取器件曲线** | 器件曲线属于 Python 建模问题，不加载到 FPGA 硬件 |
| **FPGA 不模拟物理演化** | 不模拟电导更新、器件退化或物理效应 |
| **Cyclone IV 约束** | 资源有限（~10K–22K LE），网络设计受此约束 |

### FPGA 数字推理模块

```
输入适配 → 定点量化 → 缓冲 → MAC/卷积层 → 激活 → 池化（如有）
→ 全连接 → argmax → 分类输出
```

设计考虑：
- **并行度权衡**：全并行、部分并行、或时分复用
- **权重存储**：片上 M9K BRAM 或 LUTRAM
- **资源平衡**：LE / M9K / DSP 块（如有）的使用平衡
- **数值精度**：定点位宽、饱和/舍入/溢出处理策略
- **验证**：Python 与 RTL bit-accurate 逐层对比

> 工具链为 Quartus + ModelSim/Questa，**不使用** Vivado / FINN / PYNQ / Xilinx 工具链。

## 辅助关系 C：器件曲线与模型参数（离线算法联系）

```
论文曲线 / 未来 4×4 实测曲线
  ⇢ Python 器件曲线模型或自定义优化器
    ⇢ 生成受器件约束的数字等效权重
      ⇢ 与普通 Adam 权重对照
```

| 项目 | 说明 |
|------|------|
| 这不是实时硬件接口 | 是离线数据处理流程 |
| FPGA 不受影响 | FPGA 仅部署最终数字权重，不读取曲线或不运行器件模型 |
| 曲线来源 | 先用课题组论文数据，未来用 4×4 实测数据替换 |
| 研究内容 | 器件非线性约束下的权重更新、差分电导表示、有限状态影响 |

## 模块依赖关系

### A 轨依赖

| 前置条件 | 后续任务 |
|----------|----------|
| 器件 pinout、端口功能 | 确定保护/偏置电路方案 |
| 电气规格（电压/电流/时序） | 确定读出电路、ADC 选型 |
| 阵列拓扑 | 确定通道选择和 MUX 方案 |
| 光源条件 | 设计光学输入方案 |
| 最快响应时间 / 最长衰减 | 派生采样率要求 |

### B 轨依赖

| 前置条件 | 后续任务 |
|----------|----------|
| CNN 具体架构确定 | 训练代码开发 |
| FPGA 具体型号和资源 | 网络规模上限确定 |
| 定点位宽和量化方案 | RTL 实现 |

> B 轨不依赖 A 轨的器件信息，可独立推进。
