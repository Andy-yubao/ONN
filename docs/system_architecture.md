# 系统架构

> **当前状态**：系统架构待 M0 阶段充分阅读论文后确定。
> 以下为初步框架，包含大量待确认项。

## 可能的数据链路（待确认）

```
信号输入（待确认具体形式）
    ↓
光学器件 / 模拟信号（或器件特性仿真数据）
    ↓
模拟前端：放大、滤波、偏置（如需要）
    ↓
ADC 模数转换（如需要）
    ↓
FPGA 数据接收与处理
    ↓
神经网络前向推理
    ↓
结果输出
```

> ⚠️ **注意**：目前的输入形式尚不明确。虽然任务是图像分类，但输入大概率不是由一瞬间的电信号决定，而需要对一段时间内的数据进行处理后再送入网络计算。具体的采样策略、编码方式和时间窗口长度待论文阅读后确定。
