# 系统架构

> **当前状态**：路线 B 的 MNIST 数字基线已完整落地（软件基线 → 量化 → 完整 RTL → 50 MHz STA → 固定 digit8 板级自检）；路线 A 仍为架构规划。两条路线之间当前无强制实时数据接口，但允许并需要离线算法耦合（路线 A 的响应模型为路线 B 的训练数据变换提供依据）。

---

## 路线 A：光电突触阵列信号采集与光功率重建

### 架构图

```
固定波长激光输入
       ↓
4×4 光电突触阵列（持续特性：状态依赖 / 多次采样）
       ↓
偏置与电流读出（可控/可配置偏置）
       ↓
模拟信号调理（电流 → ADC 可采电压）
       ↓
ADC
       ↓
┌─────────────────────────────────────┐
│ FPGA 采样、缓存和控制               │
│  ├─ 可配置采样参数                   │
│  │   (sample_period, start_delay,    │
│  │    sample_count, average_count)   │
│  ├─ 表征模式 / 稳态测量模式          │
│  ├─ 多次采样 / 动态曲线记录          │
│  └─ 原始 ADC 数据保留/导出          │
├─────────────────────────────────────┤
│ FPGA 校正与归一化                    │
│  ├─ 零点/增益校正                    │
│  └─ 响应归一化                      │
├─────────────────────────────────────┤
│ FPGA 光功率估计（协议限定）          │
│  ├─ LUT / 分段线性插值               │
│  └─ 定点多项式（无浮点指数/对数）    │
└─────────────────────────────────────┘
       ↓
带时间戳响应序列 + 4×4 光功率矩阵（受条件约束）
       ↓
数据传输或显示
```

### 设计原则

| 原则 | 说明 |
|------|------|
| 需要偏置 | 零偏置读取不够稳定，工程基线采用可控配置偏置；偏置值待实验确定 |
| **多次采样与状态依赖** | 器件具有持续特性（记忆、慢衰减），原始交付是带时间戳的多通道响应序列；光功率估计需限定测量协议 |
| 离线标定 | PC 端拟合模型参数，FPGA 只使用已标定参数完成在线计算 |
| 不锁定具体型号 | TIA/ADC/运放的具体型号待器件参数确认后选择 |
| 配置优先 | 采样参数可配置，第一版实现两种基本工作方式（表征/稳态），不追求全功能瞬态捕获 |
| 原始数据保留 | ADC 原始码、校正值、归一化值、光功率估计值都是有效数据输出 |
| 安全优先 | 所有电路设计以安全读出为第一原则 |

### FPGA 在路线 A 中的职责

- ADC 采样控制
- 数据缓存
- 多次采样 / 动态曲线记录
- 原始值校正（零点/增益）
- 响应归一化
- 协议限定下的光功率估计（LUT/分段线性/定点多项式）
- 输出带时间戳响应序列与受条件约束的 4×4 光功率矩阵
- 原始 ADC 数据导出

> FPGA **不**负责在线重新拟合模型参数。

## 路线 B：类脑 CNN 训练研究与 FPGA 推理部署

### 架构图（已完成基线）

```
MNIST 28×28 单通道灰度图
       ↓
┌──────────────────────────────────────┐
│ PC 端：标准反向传播训练基线（已完成） │
│  ├─ BaselineCNN                     │
│  └─ Tiny-ResNet / 浅层残差 CNN       │
├──────────────────────────────────────┤
│ PC 端：量化与参数导出（已完成）      │
│  ├─ BN 融合                          │
│  ├─ INT8 PTQ（方案 A，per-tensor）   │
│  ├─ 纯整数参考模型（bit-accurate）   │
│  └─ 权重/偏置/测试向量导出           │
└──────────────────────────────────────┘
       ↓
┌──────────────────────────────────────┐
│ FPGA：定点 CNN 前向推理（已完成）    │
│  ├─ 完整纯计算核心（baseline_cnn_core）│
│  ├─ stem/pool/conv2/pool2/conv3/GAP/FC/argmax │
│  ├─ 50 MHz STA（最小 Fmax 56.41 MHz）│
│  └─ 固定 digit8 板级自检（AC620）    │
└──────────────────────────────────────┘
       ↓
分类结果（0–9）和性能数据

（新增研究方向）
标准 RGB 图像 → 器件响应模型 → 电导/电流表示 → 训练与评价
  ├─ 定向 Hebbian 连接增强（公式待定）
  ├─ KAN 候选（结构待定）
  └─ 多次采样与时序特征（编码方式待定）
```

### 设计原则

| 原则 | 说明 |
|------|------|
| 纯数字推理 | FPGA 执行标准定点 CNN 前向计算，不涉及物理器件 |
| 训练完全离线 | 所有训练在 PC 端完成，FPGA 不执行在线训练或权重更新 |
| 独立输入 | 已完成基线的输入为 MNIST 数字图像，不来自路线 A 的实时采集电路 |
| 基线优先 | 标准反向传播基线已建立；研究性训练规则与数字基线部署**并行**，不是其前置条件 |
| Cyclone IV E 约束 | EP4CE10F17C8（~10K LE），完整核心 Fitter 实测 LE 2,933 / M9K 30（63%） |
| 28×28 ≠ 4×4 | 已完成基线输入与路线 A 输出尺寸不同，但不构成矛盾——二者为独立路线 |

### FPGA 在路线 B 中的职责（已完成）

- 加载定点权重和偏置（片上 ROM）
- 执行完整定点 CNN 前向推理（stem → pool1 → conv2 → pool2 → conv3 → GAP → FC → argmax）
- 输出分类结果（prediction）
- 提供资源占用和时序报告（50 MHz STA 满足）

> FPGA **不**读取器件曲线、不模拟物理演化、不执行在线训练。板级验证为固定 digit8、片上 ROM 输入自检，**非任意输入部署**。

## 两条路线的关系

```
路线 A：带时间戳响应序列 + 4×4 光功率矩阵（受条件约束）
       ↕ 研究主题相关；无强制实时数据接口；允许并需要离线算法耦合
路线 B：28×28 MNIST CNN 推理（已完成） + 器件模型驱动训练（新增）
```

| 方面 | 路线 A | 路线 B |
|------|--------|--------|
| 输入 | 固定波长激光 → 4×4 阵列 | MNIST 28×28 灰度图（已完成基线）；标准 RGB → 电导/电流表示（新增方向） |
| 输出 | 带时间戳响应序列 + 受条件约束的 4×4 光功率矩阵 | 0–9 分类结果 |
| FPGA 角色 | 采样控制、多次采样、校正、归一化、协议限定光功率估计 | CNN 前向推理（已完成） |
| 模拟电路 | 需要（偏置/读出/调理/ADC） | 不需要（纯数字） |
| 训练 | 离线标定（PC 端拟合模型） | 离线训练（PC 端） |
| 器件依赖 | 直接依赖 | 已完成基线不依赖；新增方向经响应模型离线依赖 |

## 当前不做

- 实时硬件端到端联调（离线算法耦合除外）
- 阵列内 VMM / 模拟计算
- FPGA 在线训练或权重更新
- SNN / 储备池计算
- 端到端光电识别系统
- Vivado / FINN / PYNQ 工具链
