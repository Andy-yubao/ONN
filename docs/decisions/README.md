# 设计决策记录

> 每当遇到一个重要选择，在此记录决策过程。
> 文件命名方式：`NNN-decision-title.md`

## 记录原则

每份决策记录包括：

1. **问题**：需要决策的问题是什么
2. **方案**：考虑过哪些选项
3. **选择**：最终采用了哪个方案
4. **原因**：选择该方案的理由
5. **后果**：该选择可能带来的影响
