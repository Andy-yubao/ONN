# ADR 005：外围采集系统支持多档可配置采样率

| 字段 | 值 |
|------|-----|
| **状态** | Accepted |
| **提出日期** | 2026-07-19 |
| **最后更新** | 2026-07-19 |

## 问题

4×4 采集系统应支持什么采样能力？

## 考虑过的方案

1. **固定单一采样率**：一种采样率满足所有实验需求
2. **多档可配置采样率**：支持快速瞬态、常规曲线、长时监测三种逻辑模式
3. **最高采样率始终运行**：所有实验都以最高采样率运行，通过软件降采样

## 选择

**方案 2：多档可配置采样率。**

## 原因

1. 器件表征需要覆盖从微秒级瞬态到小时级衰减的大跨度时间尺度
2. 固定单一采样率无法同时满足瞬态捕获和数据量控制的需求
3. 始终运行最高采样率会产生大量冗余数据，增加传输和存储压力
4. 多档模式降低认知负担：实验者按目的选择模式，而非手动配置频率
5. "高频采样"是能力要求，不等于所有实验始终以最高采样率运行

## 后果

- 系统设计支持至少三种逻辑采样模式：快速瞬态、常规曲线、长时监测
- 具体采样率数值由器件最快有效响应、模拟带宽、MUX 建立时间、ADC 吞吐率和数据传输能力派生
- 最高档服务瞬态捕获，低速档服务长时监测
- 不得未经论证写死具体采样率数值
- 单通道有效采样率需考虑 MUX 开销（若使用）
