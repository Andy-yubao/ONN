# ADR 004：当前不要求端到端集成

| 字段 | 值 |
|------|-----|
| **状态** | Accepted |
| **提出日期** | 2026-07-19 |
| **最后更新** | 2026-07-19 |

## 问题

当前项目阶段是否要求 4×4 外围采集系统与 28×28 CNN FPGA 推理系统实现物理端到端连接？

## 考虑过的方案

1. **要求端到端**：4×4 采集输出必须直接连接 FPGA CNN 输入
2. **不要求连接**：两部分各自独立验证交付
3. **预留接口但暂不实现**：定义接口但不实现物理连接

## 选择

**方案 2：当前不要求端到端连接。**

## 原因

1. 器件接口未知前不能定型任何"前端到后端"的信号链
2. 4×4 是传感器阵列，不是 28×28 CNN 的输入源——尺寸和功能都不匹配
3. 强行要求连接会导致项目被阻塞在无法控制的外部因素上
4. 两部分各自有独立的研究价值和交付标准

## 后果

- 任何文档中不能将"端到端联调"描述为当前阶段的成功标准
- 项目成果不能包装成完整光电识别闭环系统
- 未来若条件成熟，探索算法层的离线联系（器件曲线 → Python 权重更新）
