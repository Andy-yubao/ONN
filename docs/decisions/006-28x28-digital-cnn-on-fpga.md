# ADR 006：FPGA 实现 28×28 数字 CNN 推理

| 字段 | 值 |
|------|-----|
| **状态** | Accepted |
| **提出日期** | 2026-07-19 |
| **最后更新** | 2026-07-19 |

## 问题

FPGA 推理目标是什么？网络结构、输入和使用器件信息吗？

## 考虑过的方案

1. **端到端光电 CNN**：FPGA 接收 4×4 采集数据，完成包括物理器件推理的完整链路
2. **纯数字 28×28 CNN 推理**：FPGA 部署标准数字 CNN，接收数字图像输入，不依赖物理器件
3. **SNN/RC**：使用脉冲神经网络或储备池计算

## 选择

**方案 2：FPGA 实现 28×28 数字 CNN 前向推理。**

## 条件

- 普通 Adam 训练是 FPGA 推理基线和器件曲线优化方法的对照，不是多余任务
- 器件曲线优化不阻塞 FPGA 推理
- 网络结构在 M1 阶段确定，受 Cyclone IV 资源约束

## 原因

1. 器件接口未知不阻塞纯数字推理链路的开发
2. 28×28 MNIST CNN 是文献中最广泛验证的 FPGA 推理基线
3. 基于 P4 定量比较 [P4]，CNN 比 SNN 更适合 FPGA 上的小任务分类
4. 普通 Adam 基线提供确定性的参考点，用于评估器件曲线优化的影响
5. 完成后可获得完整的"训练→量化→部署→验证"工作流

## 后果

- FPGA 只部署最终数字等效权重，不在推理时重放器件曲线
- 物理光学器件不参与 FPGA 上的乘加
- 输入来自数字数据源，不来自 4×4 采集电路
- 硬件平台为小梅哥 AC620（Cyclone IV），工具为 Quartus + ModelSim/Questa
- 不使用 Vivado / FINN / PYNQ / Xilinx 工具链
