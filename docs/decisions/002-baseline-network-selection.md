# ADR 002：第一版数字基线网络选择

| 字段 | 值 |
|------|-----|
| **状态** | Proposed |
| **提出日期** | 2026-07-19 |
| **最后更新** | 2026-07-19 |

## 问题

第一版数字基线应选用哪种网络结构？

## 考虑过的方案

1. **小型定点 ANN/CNN**：优先比较全连接网络和小卷积网络
2. **SNN（脉冲神经网络）**：利用"突触"名称的直觉
3. **RC（储备池计算）**：利用 P2 展示的时序编码
4. **不做选择，全部尝试**

## 选择

**方案 1：优先比较小型定点 ANN/CNN。**

## 原因

1. 基于 P4 的系统性比较 [P4]：对于 MNIST 这类小任务，SNN 在延迟和能效上不具稳定优势
2. SNN 需要膜电位存储和事件队列管理，消耗额外 FPGA 资源
3. 小型 ANN/CNN 在数字实现上更直接、更容易在 Cyclone IV 上部署
4. 器件名为"突触"不意味着必须使用 SNN——"突触"指器件模拟生物突触的可塑性，不是算法约束
5. 后续可根据器件的时序数据决定是否需要 SNN/RC

## 条件

- 第一版基线只是**建议优先选择**，不是未经评估的最终结论
- SNN/RC 作为**条件分支**保留
- 最终网络选择将依据以下决策：
  - 器件实测时序数据是否有利用价值
  - FPGA 资源是否足以支持所选网络
  - 任务准确率、延迟、功耗和复杂度综合比较

## 后果

- M1 阶段将实现全连接和/或小 CNN 的定点推理
- 训练框架暂定 PyTorch
- 后续若器件时序特性展示明显优势，可添加 SNN/RC 分支比较
