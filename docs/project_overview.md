# 课题总览

> 本文档说明项目背景、两条路线的目标、当前边界及研究价值。

---

## 科研背景

光电突触器件能够将光感知与记忆可塑性结合，为低功耗类脑感知与计算提供新的硬件途径。课题组在 GDY/WSe₂ 异质结构光电突触器件上已展示宽光谱响应（405–980 nm）、短/长期记忆可塑性和时序编码能力 [P2]。

然而，从单一器件到可用的原型系统存在巨大的工程跨越。本项目围绕课题组正在制作的 `4×4` 光电突触阵列，将工程挑战拆解为**两条在研究主题上相关、但在当前工程阶段不要求耦合的路线**，各有独立的输入、输出、验证方式和开发进度，可以分别完成和验收。

---

## 路线 A：光电突触阵列信号采集与光功率重建

### 目标

为课题组 `4×4` 光电突触阵列设计偏置与电流读出电路、模拟信号调理、ADC 采样和 FPGA 数字处理系统，实现从器件光电流响应到 `4×4` 光功率矩阵的完整采集与重建链路。

### 输入与输出

| 项目 | 说明 |
|------|------|
| 输入 | 固定波长激光（波长已定，当前可不考虑波长-功率耦合） |
| 中间数据 | ADC 原始码值序列、经校正的响应值、归一化响应值 |
| 最终输出 | `4×4` 光功率矩阵（可解释为 4×4 单通道灰度图像） |
| 当前不要求 | 将该 4×4 矩阵直接输入路线 B 的 28×28 CNN |

### 数据链路

```
固定波长激光输入
  → 4×4 光电突触阵列
    → 带偏置的电流读出与模拟信号调理
      → ADC
        → FPGA 采样、缓存和控制
          → 零点/增益校正
            → 响应归一化
              → 光功率映射
                → 4×4 光功率矩阵
                  → 数据传输或显示
```

### 关键工程要点

| 要点 | 说明 |
|------|------|
| 偏置读取 | 零偏置读取不够稳定，工程基线采用可控或可配置偏置；具体偏置值需实验确定 |
| 模拟前端 | 需完成电流到 ADC 可采电压的转换；TIA 为候选方案，尚未锁定具体拓扑 |
| 采样策略 | 第一版支持可配置参数（采样周期、等待时间、采样数量、平均窗口）；实现表征模式和稳态测量模式两种基本工作方式 |
| 默认采样率 | `1 kHz` 为早期实验起始配置，非固定值 |
| 离线标定 | PC 端使用 Python/MATLAB 采集已知光功率下的响应，拟合经验模型，生成参数/LUT |
| FPGA 在线计算 | FPGA 负责 ADC 控制、缓存、校正、归一化、使用已标定模型估计光功率；不负责在线重拟合模型参数 |
| 原始数据保留 | ADC 原始数据必须能够保留或导出，不能只保留归一化结果 |

## 路线 B：类脑 CNN 训练研究与 FPGA 推理部署

### 目标

以 MNIST `28×28` 单通道灰度图为输入，在 PC 端建立标准 CNN 训练基线，探索候选类脑更新规则，最终在 Cyclone IV FPGA 上部署定点前向推理。

### 输入与输出

| 项目 | 说明 |
|------|------|
| 数据集 | MNIST 手写数字 |
| 输入 | `28×28` 单通道灰度图像 |
| 训练 | 完全在 PC 端离线完成 |
| FPGA 职责 | 只执行前向推理，不执行在线训练 |
| 输出 | 0–9 分类结果和性能数据 |

### 数据链路

```
MNIST 28×28 灰度图
  → PC 端标准反向传播训练基线
    → 类脑更新规则实验（候选方向）
      → 量化与参数导出
        → FPGA 定点 CNN 前向推理
          → 分类结果和性能评价
```

### 网络结构

- **候选主架构**：Tiny-ResNet、浅层残差 CNN 或 ResNet-8 级别（Cyclone IV 资源有限，MNIST 规模较小）
- **对照基线**：普通 CNN 或 LeNet 类模型

### 类脑更新规则研究方向

核心直觉：经常参与有效计算的连接得到增强，长期不活跃或贡献较小的连接逐渐削弱。

**候选研究方向（非既定方案）**：
- Hebbian learning
- Oja 或其他带稳定项的 Hebbian 变体
- 活动依赖的权重增强与衰减
- 奖励或误差信号调制的三因素学习规则
- 梯度下降与局部可塑性规则的混合
- Hebbian 预训练加反向传播微调

> **注意**：本项目不宣称一定采用 STDP，也不宣称类脑规则必然提高准确率。Dropout 可作为普通正则化基线，但不是本项目类脑更新规则的定义。

### 推荐实验结构

```
普通 CNN + 标准反向传播
浅层残差 CNN + 标准反向传播
浅层残差 CNN + 候选类脑更新规则
（必要时）普通 CNN + 候选类脑更新规则
```

### 评价维度

| 维度 | 说明 |
|------|------|
| 分类准确率 | 基线对照 |
| 收敛速度 | 训练轮次对比 |
| 权重稀疏度 | 连接精简程度 |
| 鲁棒性 | 对输入噪声和遮挡的容忍度 |
| 低比特量化适应性 | 量化后精度保持 |
| FPGA 资源占用 | LE/M9K/DSP 使用率 |
| 推理延迟 | 时钟周期数 |
| 功耗或能耗估计 | 系统级评估 |

> 以上是候选评价维度，不预先承诺类脑方法同时改善所有指标。

## 两条路线的关系

| 方面 | 说明 |
|------|------|
| 共同研究主题 | 低功耗类脑感知与计算 |
| 路线 A 输出 | `4×4` 光功率矩阵 |
| 路线 B 输入 | `28×28` MNIST 灰度图 |
| 当前无强制接口 | 不要求插值、上采样或转换后联调 |
| 独立开发 | 两条路线可独立开发、独立验证和独立验收 |
| 未来可能性 | 若两条路线均成功，未来可探索算法层面的联系；此为非承诺的远期选项 |

## 风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| 器件 pinout/规格长期无法获得 | 🔴 高 | 路线 B 不依赖此信息，可先启动 |
| 器件阵列与论文参数差异大 | 🟡 中 | 路线 A 从安全表征开始，逐步确认 |
| FPGA 资源不足以部署目标 CNN | 🟡 中 | 有全连接等轻量方案作为备份 |
| 4×4 单元一致性差影响表征 | 🟡 中 | 先验证单通道，评估后再决定策略 |
