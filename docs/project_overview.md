# 课题总览

> 本文档说明项目背景、两条独立主线的选择逻辑、研究价值及当前交付边界。

---

## 科研背景

光电突触器件能够将光感知与记忆可塑性结合，为类脑计算和智能感知提供新的硬件途径。课题组在 GDY/WSe₂ 异质结构光电突触器件上已展示宽光谱响应（405–980 nm）、短/长期记忆可塑性和时序编码能力 [P2]。

然而，从单器件到可用的原型系统存在巨大工程跨越。本项目以当前实物的 4×4 小阵列为起点，将工程挑战拆解为**两个相对独立、可并行推进的子系统**，各自形成可验证的交付物，避免因单一端到端链路中的任意环节阻塞导致整体停滞。

---

## 两条独立主线

### 主线 A：4×4 器件外围采集系统

**目标**：为 4×4 光学突触阵列设计传感器外围采集电路，实现安全读出、多档采样和曲线数据保存。

| 项目 | 说明 |
|------|------|
| 核心功能 | 受控光刺激 → 器件响应 → 模拟读出 → 数字化 → PC 保存 |
| 交付性质 | 器件表征和数据采集系统，**不是计算阵列** |
| 4×4 的充分性 | 16 单元足以验证多通道采集、通道扫描、多档采样等核心能力 |
| 关键约束 | 器件 pinout 和安全规格未知前无法定型电路 |

**成功标准**：安全、稳定、可配置时间分辨率地获得器件数字响应曲线。

### 主线 B：28×28 CNN FPGA 数字推理

**目标**：在 Cyclone IV FPGA 上部署接受 28×28 手写数字输入的数字 CNN 推理模型。

| 项目 | 说明 |
|------|------|
| 核心功能 | 标准 28×28 MNIST 图像 → Python 训练 → 定点化 → FPGA 前向推理 → 0–9 分类 |
| 交付性质 | 纯数字 FPGA 推理系统，**不依赖物理器件** |
| 输入来源 | 数字数据源（testbench/ROM/PC 传输） |
| 硬件平台 | 小梅哥 AC620（Cyclone IV），Quartus + ModelSim/Questa |

**成功标准**：对 28×28 数字图像执行完整 CNN 前向推理，输出分类结果。

### 采用双主线的理由

1. **解耦风险**：器件接口未知不阻塞 FPGA 数字推理的开发
2. **明确交付**：每条主线有独立可验证的完成标准
3. **资源并行**：两部分可独立推进
4. **降低认知负担**：避免用"未来可能"模糊当前实际任务

### 两条主线的当前关系

```
主线 A：4×4 → 外围采集 → 数字曲线（器件表征）
                                            [离线弱联系]
主线 B：28×28 图像 → Python CNN → FPGA 数字推理（数字分类）
```

当前不要求物理 A→B 连接。二者只可能在算法层形成离线弱联系：

```
器件曲线 → Python 模型参数更新 → 数字权重 → FPGA 部署
```

## 4×4 足够做什么

4×4 阵列（16 单元）足以完成以下验证：

- **采集系统验证**：多通道选通、多档采样、长时监测
- **器件表征**：暗态、光响应、脉冲响应、衰减特性
- **基础功能验证**：通道扫描、时间戳记录、数据保存
- **曲线数据获取**：为器件建模提供第一手实测数据

> 4×4 太小不再构成"与 28×28 输入矛盾"的问题——因为 4×4 不是 28×28 CNN 的直接输入，二者是独立主线。

---

## 器件曲线研究的辅助地位

器件曲线处理（光响应曲线、权重更新曲线、差分电导更新）属于 **Python 训练/建模问题**：

- 使用课题组论文参数训练数字等效权重
- 探索器件约束下的参数更新方法
- 与普通 Adam 基线对照

这**不改变 FPGA 推理的数字性质**，不涉及硬件端到端连接。详见 [project_scope.md](project_scope.md) 辅助研究任务 C。

## 当前交付与不交付

### 当前交付（M0 阶段）

- [x] 双主线范围定义和文档统一
- [ ] 4×4 器件接口确认（pinout、安全规格）
- [ ] CNN 具体架构确认
- [ ] 采样性能派生和需求细化

### 当前不交付

- 4×4 → FPGA CNN 端到端连接
- 物理计算阵列
- 完整光电识别系统
- SNN 或储备池计算
- 在线训练或权重更新

---

## 未来愿景

若两条主线均成功，未来可探索：

1. **算法层整合**：使用 4×4 实测曲线训练/校准 FPGA 部署的数字权重
2. **系统集成**：若获得更大阵列且外围电路成熟，可探索前端的直接连接
3. **方法推广**：器件曲线优化方法从 CNN 推广到更复杂网络

上述均为远期选项，**不构成当前承诺**。

## 风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| 器件 pinout/规格长期无法获得 | 🔴 高 | B 轨不依赖此信息，可先启动 |
| 器件阵列与论文参数差异大 | 🟡 中 | A 轨从安全表征开始，逐步确认 |
| FPGA 资源不足以部署目标 CNN | 🟡 中 | 有全连接等轻量方案作为备份 |
| 4×4 单元一致性差影响表征 | 🟡 中 | 先验证单通道，评估后再决定策略 |
