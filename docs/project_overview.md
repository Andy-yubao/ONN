# 课题总览

## 研究背景

类脑感知是下一代智能感知与边缘计算的核心方向。传统神经网络依赖 GPU 等高性能计算平台，功耗高、体积大，难以满足边缘端和极端环境下的部署需求。

二维半导体神经形态器件因其超宽禁带、高鲁棒性和类突触可塑性，在低功耗感知领域展现出巨大潜力。然而，器件输出信号微弱、易受噪声干扰，且外围电路与 FPGA 部署之间存在复杂的协同设计问题。

本课题聚焦二维半导体神经形态器件的**外围电路设计**、**FPGA 系统集成**与 **ONN 算法优化**，构建"器件建模 → 电路设计 → FPGA 部署 → 算法优化 → 系统验证"的完整技术路线。

## 最终目标系统

### 最终理想系统

| 项目 | 描述 |
|------|------|
| 输入 | 光学图像信号 |
| 输出 | 分类识别结果 |
| 光学前端 | 二维半导体光电突触器件接收光刺激，输出模拟电信号 |
| 外围电路 | 弱信号放大、滤波、脉冲驱动、ADC 采集 |
| FPGA | 数据接收、预处理、神经网络前向推理、结果输出 |
| 神经网络 | 利用器件电导特性训练的轻量化网络（待定具体结构） |
| 协同优化 | 器件-电路-FPGA-算法 四层协同 |

> **输入方式待确认**：虽然任务可能是 RGB 三通道图像分类，但输入信号大概率不是由一瞬间的电信号决定，而是需要对一段时间内的数据进行处理后送入网络。具体输入形式和编码方式需充分阅读论文后确定。

## 各模块职责

| 模块 | 功能 | 状态 |
|------|------|------|
| 光电突触器件（特性数据） | 提供电导态、STDP 曲线等参数，用于定义训练优化器 | 课题组提供 |
| 外围电路 | 微弱信号调理（放大/滤波）、脉冲驱动、ADC 转换 | 待系统框架明确 |
| FPGA | 数据接收、缓存、推理、结果显示 | 待系统框架明确 |
| PC 端训练 | 基于器件参数训练网络，导出 FPGA 可部署权重 | 待确定网络结构 |

## 当前仍未确定的问题

详见 [open_questions.md](open_questions.md)。核心待确认问题包括：

- **器件使用方式**：特性数据如何参与训练
- **硬件平台**：具体 FPGA 型号和资源
