# 课题总览

> 事实基线见 [project_scope.md](project_scope.md)；本文件为背景与解释。

## 科研背景

光电突触器件能够将光感知与记忆可塑性结合，为低功耗类脑感知与计算提供新的硬件途径。课题组在 GDY/WSe₂ 异质结构光电突触器件上已展示宽光谱响应（405–980 nm）、短/长期记忆可塑性和时序编码能力 [P2]。

然而，从单一器件到可用的原型系统存在巨大的工程跨越。本项目围绕课题组正在制作的 `4×4` 光电突触阵列，将工程挑战拆解为**两条在研究主题上相关、在当前工程阶段不要求实时耦合、但允许并需要离线算法耦合的路线**。

## 路线 A：光电突触阵列信号采集与光功率重建

### 目标

为课题组 `4×4` 光电突触阵列设计偏置与电流读出电路、模拟信号调理、ADC 采样和 FPGA 数字处理系统，实现器件的多次采样响应采集与协议限定下的光功率重建。

### 输入与输出

| 项目 | 说明 |
|------|------|
| 输入 | 固定波长激光（波长已定，当前可不考虑波长-功率耦合） |
| 中间数据 | ADC 原始码值序列、经校正的响应值、归一化响应值 |
| 原始交付 | **带时间戳的多通道电流/电压/ADC 响应序列**（支持多次采样与动态曲线记录） |
| 目标输出 | `4×4` 光功率矩阵——**仅在明确测量协议下成立的受条件约束输出** |
| 当前不要求 | 将该 4×4 矩阵直接实时输入路线 B 的 CNN |

### 数据链路

```
固定波长激光输入
  → 4×4 光电突触阵列
    → 带偏置的电流读出与模拟信号调理
      → ADC
        → FPGA 采样、缓存和控制（多次采样 / 动态曲线）
          → 零点/增益校正
            → 响应归一化
              → 协议限定下的光功率估计
                → 4×4 光功率矩阵（受条件约束） → 数据传输或显示
```

### 关键工程要点

| 要点 | 说明 |
|------|------|
| 偏置读取 | 零偏置读取不够稳定，工程基线采用可控或可配置偏置；具体偏置值需实验确定 |
| 模拟前端 | 需完成电流到 ADC 可采电压的转换；TIA 为候选方案，尚未锁定具体拓扑 |
| 采样策略 | 第一版支持可配置参数（采样周期、等待时间、采样数量、平均窗口）；实现表征模式和稳态测量模式两种基本工作方式 |
| **持续特性** | 器件响应依赖光照历史与初始状态；**多次采样**是必须支持的采样方式，单点采样"当作摄像头"不成立 |
| **稳态时间** | 会议初步估计约 20 秒到 1 分钟达到稳态，**待实物验证**，不当作 datasheet 参数 |
| 默认采样率 | `1 kHz` 为早期实验起始配置，非固定值 |
| 离线标定 | PC 端使用 Python/MATLAB 采集已知光功率下的响应，拟合经验模型，生成参数/LUT |
| FPGA 在线计算 | FPGA 负责 ADC 控制、缓存、校正、归一化、使用已标定模型估计光功率；不负责在线重拟合模型参数 |
| 原始数据保留 | ADC 原始数据必须能够保留或导出，不能只保留归一化结果 |

## 路线 B：类脑 CNN 训练研究与 FPGA 推理部署

### 目标

已完成的工程基线：以 MNIST `28×28` 单通道灰度图为输入建立软件对照基线（BaselineCNN / Tiny-ResNet），完成 BN 融合、INT8 PTQ、纯整数参考模型与参数导出，并在 Cyclone IV FPGA 上部署完整 BaselineCNN 定点前向推理（RTL、仿真、50 MHz STA、固定 digit8 板级自检）。

当前新增研究方向（2026-08-02 组会）：将标准 RGB 或其他图像经器件响应模型转换为电导/电流表示后训练与评价；定向 Hebbian 连接增强；KAN 候选探索；考虑持续特性与多次采样。

### 输入与输出

| 项目 | 说明 |
|------|------|
| 数据集（已完成基线） | MNIST 手写数字 |
| 输入（已完成基线） | `28×28` 单通道灰度图像 |
| 训练（已完成基线） | 完全在 PC 端离线完成 |
| FPGA 职责（已完成基线） | 只执行前向推理，不执行在线训练 |
| 输出（已完成基线） | 0–9 分类结果和性能数据 |
| 新增方向 | 标准 RGB 图像 → 器件响应模型 → 电导/电流表示 → 训练与评价 |

### 数据链路

```
（已完成）MNIST 28×28 灰度图
  → PC 端标准反向传播训练基线
    → BN 融合 / INT8 PTQ / 整数参考模型
      → 量化与参数导出
        → FPGA 定点 CNN 前向推理（完整 RTL → 50 MHz STA → 固定 digit8 板级自检）
          → 分类结果和性能评价
（新增研究）标准 RGB 图像 → 器件响应模型 → 电导/电流表示 → 训练与评价
```

### 网络结构

- **已落地**：BaselineCNN（无残差、硬件友好）、Tiny-ResNet（浅层残差，软件参考 / 高准确率备选）
- **候选主架构（已实现）**：Tiny-ResNet、BaselineCNN（Cyclone IV 资源有限，MNIST 规模较小）
- **对照基线**：普通 CNN / LeNet 类模型

### 类脑更新规则研究方向

核心直觉：经常参与有效计算的连接得到增强，长期不活跃或贡献较小的连接逐渐削弱。

**候选研究方向（非既定方案）**：
- **定向 Hebbian 学习**（2026-08-02 提出：仅增强对"得出正确答案"有正面作用的神经元对）
- Oja 或其他带稳定项的 Hebbian 变体
- 活动依赖的权重增强与衰减
- 奖励或误差信号调制的三因素学习规则
- KAN（Kolmogorov–Arnold Networks）候选
- 梯度下降与局部可塑性规则的混合

> **注意**：本项目不宣称一定采用 STDP，也不宣称类脑规则必然提高准确率。Hebbian 数学公式与 KAN 结构均待设计，标为开放问题。

### 评价维度

| 维度 | 说明 |
|------|------|
| 分类准确率 | 基线对照 |
| 收敛速度 | 训练轮次对比 |
| 权重稀疏度 | 连接精简程度 |
| 鲁棒性 | 对输入噪声和遮挡的容忍度 |
| 低比特量化适应性 | 量化后精度保持 |
| FPGA 资源占用 | LE/M9K/DSP 使用率 |
| 推理延迟 | 时钟周期数（当前 1,590,315 cycles ≈ 31.81 ms @ 50 MHz） |
| 功耗或能耗估计 | 系统级评估（未实测） |

> 以上是候选评价维度，不预先承诺类脑方法同时改善所有指标。

## 两条路线的关系

| 方面 | 说明 |
|------|------|
| 共同研究主题 | 低功耗类脑感知与计算 |
| 路线 A 输出 | 带时间戳响应序列 + 协议限定下的 4×4 光功率矩阵 |
| 路线 B 输入（已完成基线） | `28×28` MNIST 灰度图 |
| 当前无强制实时接口 | 不要求插值、上采样或转换后实时联调 |
| **允许且需要离线算法耦合** | 路线 A 的器件表征和响应模型可为路线 B 的训练数据变换提供依据 |
| 独立开发 | 两条路线可独立开发、独立验证和独立验收 |
| 未来可能性 | 若两条路线均成功，未来可探索更深度的耦合；此为非承诺的远期选项 |

## 当前交付与不交付

### 已交付

- [x] 双路线范围定义和文档统一
- [x] MNIST 软件基线（BaselineCNN / Tiny-ResNet）与多种子审计
- [x] BaselineCNN BN 融合、INT8 PTQ、纯整数参考模型与参数导出
- [x] 完整 BaselineCNN 纯计算核心 RTL 与仿真验证、Quartus 综合、50 MHz STA
- [x] 固定 digit8、片上 ROM 输入的 AC620 板级自检（JTAG SRAM 配置）
- [x] 2026-08-02 组会决定的方向记录与 ADR 008

### 尚未交付

- [ ] 器件测量方案和前端采集原型（M1-A）
- [ ] 外部任意图像输入与 UART 图像传输（M3-B.4）
- [ ] 测试集级硬件准确率（≥1000 张）（M3-B.4）
- [ ] 功耗或单次推理能耗实测（M4-B）
- [ ] EPCS Flash 固化
- [ ] 器件模型驱动训练（RGB → 电导/电流表示）数据与实验
- [ ] 定向 Hebbian 规则与 KAN 实验

### 当前不交付

- 实时硬件端到端联调（离线算法耦合除外）
- 阵列内 VMM / 模拟计算
- FPGA 在线训练或权重更新
- SNN 或储备池计算
- 完整的实时光电识别系统

## 风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| 器件 pinout/规格长期无法获得 | 🔴 高 | 路线 B 不依赖此信息，数字基线已独立完成 |
| 器件阵列与论文参数差异大 | 🟡 中 | 路线 A 从安全表征开始，逐步确认；稳态时间等标为待实测 |
| FPGA 资源不足以部署目标 CNN | 🟡 中 | 已冻结 EP4CE10F17C8，完整核心 Fitter 实测 M9K 63% / LE 2,933，资源可控 |
| 4×4 单元一致性差影响表征 | 🟡 中 | 先验证单通道，评估后再决定策略 |
| 器件持续特性使单点采样失真 | 🟡 中 | 必须支持多次采样与动态曲线记录 |
