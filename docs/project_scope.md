# 项目范围基线

> **本文档是项目范围的唯一事实源。** 其他文档链接至此，不各自重新定义项目目标。

---

## 一句话定义

> 本项目包含两条在研究主题上相关、但在当前工程阶段不要求耦合的路线：**路线 A** 为 `4×4` 光电突触阵列设计信号采集与光功率重建系统，实现器件响应测量到 `4×4` 光功率矩阵输出的完整链路；**路线 B** 以 MNIST `28×28` 单通道灰度图为输入，在 PC 端完成 CNN 训练和类脑学习规则探索，在 Cyclone IV FPGA 上部署定点前向推理。两条路线可独立开发、独立验证和独立验收。

---

## 固定交付物 A：光电突触阵列信号采集与光功率重建

为 `4×4` 光电突触阵列设计偏置与读出电路、模拟信号调理、ADC 采样和 FPGA 数字处理系统。

### 数据链路

```
固定波长激光输入 → 4×4 阵列 → 偏置与电流读出 → 模拟调理 → ADC
→ FPGA 采样/缓存 → 零点/增益校正 → 归一化 → 光功率映射 → 4×4 光功率矩阵
```

### 交付物清单

- [ ] 外围电路设计（偏置/保护/电流读出/模拟调理/模数转换）
- [ ] 安全读出方案（限流、限压、上电顺序）
- [ ] 可控或可配置偏置
- [ ] FPGA 采样控制与可配置采样参数（sample_period, start_delay, sample_count, average_count）
- [ ] 两种基本工作方式：表征模式（连续记录）和稳态测量模式（平均后估计光功率）
- [ ] 零点/增益校正
- [ ] 响应归一化
- [ ] 光功率映射（LUT/分段线性/定点多项式，无浮点指数/对数承诺）
- [ ] 4×4 光功率矩阵输出
- [ ] 原始 ADC 数据保留与导出
- [ ] 离线标定流程（PC 端拟合模型参数）
- [ ] 带时间戳的 ADC 数字序列保存
- [ ] 标定后的电压/电流/光功率换算

### 验收原则

- 采集到的数据分层次：原始 ADC 码 → 校正值 → 归一化值 → 光功率估计值
- 具体采样率由器件最快有效响应派生，**不得写死未经验证的数值**
- 不预设 16 路同步采样，不预设控制器一定是 FPGA
- 1 kHz 为起始默认值，非固定采样率
- TIA 为候选方案，不锁定具体拓扑或型号

## 固定交付物 B：类脑 CNN 训练研究与 FPGA 推理部署

以 MNIST `28×28` 单通道灰度图为输入，在 PC 端完成 CNN 训练和类脑规则实验，在 FPGA 上完成前向推理。

### 数据链路

```
MNIST 28×28 灰度图 → PC 标准 BP 训练 → 类脑规则实验 → 量化与参数导出
→ FPGA 定点 CNN 前向推理 → 分类结果与性能评价
```

### 交付物清单

- [ ] Python 浮点 CNN 训练流水线（标准反向传播基线）
- [ ] Tiny-ResNet / 浅层残差 CNN 候选架构实现
- [ ] 普通 CNN / LeNet 对照基线
- [ ] 至少一种候选类脑更新规则实验（Hebbian/Oja/三因素等）
- [ ] 类脑规则与标准 BP 的比较结果
- [ ] 定点/量化方案和参考模型
- [ ] 权重、偏置和测试数据导出
- [ ] Verilog 定点 CNN 前向推理实现
- [ ] Testbench 和仿真验证
- [ ] Python 与 RTL bit-accurate 一致性比对
- [ ] FPGA 综合和资源/频率报告
- [ ] 扩展评价（收敛速度、权重稀疏度、鲁棒性、量化适应性等）

### 验收原则

- 输入来自数字数据源，不来自路线 A 的采集电路
- 第一版必须建立标准反向传播基线，类脑规则不能阻塞 FPGA 推理链路
- FPGA 执行纯数字前向计算，物理器件不参与 FPGA 上的乘加
- 类脑规则候选但不承诺一定采用 STDP，也不承诺必然提高准确率
- 硬件平台为小梅哥 AC620（Cyclone IV），工具为 Quartus + ModelSim/Questa
- 不使用 Vivado / FINN / PYNQ / Xilinx 工具链

## 当前明确不做

以下内容不在当前项目阶段范围内：

- 路线 A → 路线 B 硬件连接或联调
- RGB 三通道输入
- CNN 处理 4×4 时间序列
- 4×4 阵列信号直接作为 28×28 CNN 输入
- FPGA 在线训练或权重更新
- 阵列内向量-矩阵乘法（VMM）
- 物理器件存储 CNN 权重
- SNN 或储备池计算
- 更大阵列（>4×4）
- 完整端到端实时光电识别系统
- 浮点指数/对数运算的 FPGA 实现
- 脉冲光捕获/循环缓冲/触发前后数据保存（第一版）

## 术语表

| 术语 | 定义 |
|------|------|
| **光电突触器件** | 具有光响应和记忆可塑性的光电器件，当前为 4×4 阵列 |
| **路线 A** | 光电突触阵列信号采集与光功率重建 |
| **路线 B** | 类脑 CNN 训练研究与 FPGA 推理部署 |
| **传感器外围电路** | 用于器件信号读出的前端电路（偏置/保护/电流读出/放大/模数转换） |
| **器件表征** | 通过受控激励测量器件的电学和光学响应特性 |
| **原始 ADC 码值** | ADC 量化后的未经处理的数字值 |
| **校准响应** | 经零点/增益校正后的响应值 |
| **归一化响应** | 无量纲相对响应（通常映射到 [0,1] 或 [-1,1]） |
| **光功率映射** | 使用已标定模型将归一化响应转换为光功率估计值 |
| **采样率** | ADC 对模拟信号进行采样的频率 |
| **总采样率** | ADC 在给定配置下的总吞吐率 |
| **单通道有效采样率** | 考虑 MUX 开销后的单通道实际采样率 |
| **表征模式** | 连续记录器件上升或衰减过程的采样方式 |
| **稳态测量模式** | 等待后可配置时间后采集若干点求平均再估计光功率的方式 |
| **标准反向传播** | 传统梯度下降 CNN 训练方法 |
| **类脑更新规则** | 受生物可塑性启发的参数更新方法（候选方向） |
| **FPGA 数字推理** | 在 FPGA 上使用定点数执行标准数字 CNN 前向计算 |
| **ONN** | 光学神经网络（Optical Neural Network）——本项目课题名称 |
