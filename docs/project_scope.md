# 项目范围基线

> **本文档是项目范围的唯一事实源。** 其他文档链接至此，不各自重新定义项目目标。
> 本文档 2026-08-02 依据实现、实验记录、硬件报告和组会记录更新，恢复事实源地位；详细证据见正文引用。

## 一句话定义

> 本项目包含两条在研究主题上相关、在当前工程阶段不要求实时耦合、但允许并需要**离线算法耦合**的路线。**路线 A** 为 `4×4` 光电突触阵列设计信号采集与光功率重建系统，原始交付是带时间戳的多通道响应序列，光功率估计仅在明确测量协议下成立；**路线 B** 以 MNIST `28×28` 灰度图完成软件对照基线并在 Cyclone IV FPGA 上部署定点前向推理，同时新增器件模型驱动训练（RGB → 电导/电流表示）、定向 Hebbian 与 KAN 研究方向。两条路线可独立开发、独立验证和独立验收。

---

## 固定交付物 A：光电突触阵列信号采集与光功率重建

为 `4×4` 光电突触阵列设计偏置与读出电路、模拟信号调理、ADC 采样和 FPGA 数字处理系统。

### 数据链路

```
固定波长激光输入 → 4×4 阵列 → 偏置与电流读出 → 模拟调理 → ADC
→ FPGA 采样/缓存（多次采样、动态曲线记录） → 零点/增益校正 → 归一化
→ 协议限定下的光功率估计 → 4×4 光功率矩阵（受条件约束）
```

### 交付物清单

- [ ] 外围电路设计（偏置/保护/电流读出/模拟调理/模数转换）
- [ ] 安全读出方案（限流、限压、上电顺序）
- [ ] 可控或可配置偏置
- [ ] FPGA 采样控制与可配置采样参数（sample_period, start_delay, sample_count, average_count）
- [ ] **多次采样与动态曲线记录**（原始交付是带时间戳的多通道电流/电压/ADC 响应序列）
- [ ] 两种基本工作方式：表征模式（连续记录）和稳态测量模式（平均后估计光功率）
- [ ] 零点/增益校正
- [ ] 响应归一化
- [ ] 光功率映射（LUT/分段线性/定点多项式，无浮点指数/对数承诺）——仅在明确测量协议下成立
- [ ] 4×4 光功率矩阵输出（受条件约束的目标输出，不覆盖原始时间序列）
- [ ] 原始 ADC 数据保留与导出
- [ ] 离线标定流程（PC 端拟合模型参数）
- [ ] 带时间戳的 ADC 数字序列保存
- [ ] 标定后的电压/电流/光功率换算

### 验收原则

- 采集到的数据分层次：原始 ADC 码 → 校正值 → 归一化值 → 光功率估计值
- **光功率估计的测量协议至少限定**：波长、偏置、初始状态或恢复条件、光照历史、等待时间、采样时刻或统计窗口、温度、使用的特征（峰值/稳态/积分/衰减常数等）、标定范围、单调性与可逆性是否成立
- 会议中"约 20 秒到 1 分钟达到稳态"仅为 **2026-08-02 组会初步估计**，必须等待实物验证，不得当作 datasheet 参数
- 具体采样率由器件最快有效响应派生，**不得写死未经验证的数值**
- 不预设 16 路同步采样，不预设控制器一定是 FPGA
- 1 kHz 为起始默认值，非固定采样率
- TIA 为候选方案，不锁定具体拓扑或型号

> **推荐措辞**：在固定波长、固定偏置、规定初始状态和采样协议下，使用离线标定模型估计标定范围内的光功率或相对光强；系统同时保留完整的多次采样响应序列。

## 固定交付物 B：类脑 CNN 训练研究与 FPGA 推理部署

### 已完成的工程基线（保留，不删除不贬低）

- MNIST BaselineCNN / Tiny-ResNet **浮点软件基线**（已完成，见 [实验结果](../experiments/model_baselines/m1_baselines/README.md)）
- M1-B.1 基线审计与可复现性加固（已完成，见 [审计实验](../experiments/model_baselines/m1_baseline_audit/README.md)）
- BaselineCNN BN 融合（已完成，见 [BN 融合](../experiments/model_deployment/baseline_cnn_bn_fusion/README.md)）
- INT8 PTQ（方案 A，已完成，见 [INT8 PTQ](../experiments/model_deployment/baseline_cnn_int8_ptq/README.md)）
- 纯整数参考模型与定点权重/偏置/测试向量导出（已完成，见 [整数参考](../experiments/model_deployment/baseline_cnn_int8_reference/README.md)）
- 完整 BaselineCNN 纯计算核心 RTL、模块级/集成级仿真验证、Quartus 综合与资源报告、50 MHz STA（已完成，见 [rtl_microarchitecture.md](../fpga/baseline_cnn/docs/rtl_microarchitecture.md)）
- **固定 digit8、片上 ROM 输入的 AC620 板级自检**（已完成，见 [hardware_target.md](../fpga/baseline_cnn/docs/hardware_target.md) §12）

### 当前新增的研究方向（2026-08-02 组会决定）

- **器件模型驱动的数据变换**：使用论文或实测器件参数，将标准 RGB 或其他图像转换为电导/电流表示，再在其上训练与评价
- **定向 Hebbian 连接增强**：仅增强对"得出正确答案"有正面作用的神经元对
- **KAN（Kolmogorov–Arnold Networks）候选探索**
- **持续特性与多次采样**：器件不能简单视为静态摄像头，需要考虑时序特性与多次采样

### 数据链路

```
（已完成）MNIST 28×28 → PC 基线训练 → BN 融合 → INT8 PTQ → 整数参考模型
  → 参数导出 → FPGA 定点 CNN 前向推理 → 完整 RTL → 50 MHz STA → 固定 digit8 板级自检
（新增研究）标准 RGB 图像 → 器件响应模型 → 电导/电流表示 → 训练与评价（Hebbian / KAN / 多次采样）
```

### 交付物清单

- [x] Python 浮点 CNN 训练流水线（标准反向传播基线）
- [x] Tiny-ResNet / BaselineCNN 候选架构实现与对照基线
- [x] 定点/量化方案和整数参考模型
- [x] 权重、偏置和测试数据导出
- [x] Verilog 定点 CNN 前向推理实现（完整纯计算核心）
- [x] Testbench 和仿真验证
- [x] Python 与 RTL bit-accurate 一致性比对
- [x] FPGA 综合和资源/频率报告（含 50 MHz STA）
- [x] 固定 digit8 板级自检（片上 ROM 输入）
- [ ] RGB 或标准图像经器件模型转换为电导/电流表示的数据集与训练（新增方向）
- [ ] 定向 Hebbian 规则实现与实验（新增方向，TBD 公式）
- [ ] KAN 候选实现（新增方向，TBD 结构）
- [ ] 外部图像输入与 UART 传输（M3-B.4）
- [ ] 测试集级硬件准确率（≥1000 张）（M3-B.4）
- [ ] 功耗或单次推理能耗实测（M4-B）
- [ ] 扩展评价（收敛速度、权重稀疏度、鲁棒性、量化适应性等）

### 验收原则

- 输入来自数字数据源；标准数字基线不依赖路线 A 的实时采集电路
- **BaselineCNN FPGA 部署依赖已冻结的软件基线和量化方案**；器件模型驱动训练、Hebbian 和 KAN 可与标准数字基线部署**并行**，**不构成现有 BaselineCNN RTL 的前置条件**（修正旧" M3-B 依赖 M2-B 类脑实验"的错误依赖）
- 未来若产生新的模型或权重，再建立独立的重新量化与重新部署任务
- FPGA 执行纯数字前向计算，物理器件不参与 FPGA 上的乘加
- 硬件平台为小梅哥 AC620 V2（Cyclone IV E），工具为 Quartus Lite + Questa
- 不使用 Vivado / FINN / PYNQ / Xilinx 工具链
- 板级自检结果**不得扩大**为"完整系统部署全部完成"

## 当前明确不做（不在当前工程阶段范围）

- **实时**硬件端到端联调（路线 A 输出直接实时输入路线 B）；离线算法耦合不在此列
- 阵列内向量-矩阵乘法（VMM）
- 物理器件存储 CNN 权重
- SNN 或储备池计算
- 更大阵列（>4×4）
- FPGA 在线训练或权重更新
- 浮点指数/对数运算的 FPGA 实现
- 脉冲光捕获/循环缓冲/触发前后数据保存（第一版）

> 注："RGB 三通道输入"不再是简单排除项——标准 RGB 图像经器件模型转换为电导/电流表示后训练是当前新增研究方向（具体数据集、矩阵尺寸、编码方式均待定，见 [open_questions.md](open_questions.md)）。

## 术语表

| 术语 | 定义 |
|------|------|
| **光电突触器件** | 具有光响应和记忆可塑性的光电器件，当前为 4×4 阵列；具有持续特性（状态依赖、记忆、慢衰减） |
| **路线 A** | 光电突触阵列信号采集与光功率重建 |
| **路线 B** | 类脑 CNN 训练研究与 FPGA 推理部署 |
| **持续特性** | 器件的响应依赖光照历史与初始状态，激励稳定时约在"20 秒到 1 分钟"内趋于稳态（**会议估计，待实测**） |
| **多次采样** | 对同一激励记录多时间点/多段响应，支持动态曲线而非单点采样 |
| **传感器外围电路** | 用于器件信号读出的前端电路（偏置/保护/电流读出/放大/模数转换） |
| **器件表征** | 通过受控激励测量器件的电学和光学响应特性 |
| **原始 ADC 码值** | ADC 量化后的未经处理的数字值 |
| **校准响应** | 经零点/增益校正后的响应值 |
| **归一化响应** | 无量纲相对响应（通常映射到 [0,1] 或 [-1,1]） |
| **光功率估计** | 在明确测量协议下，使用已标定模型将归一化响应转换为光功率估计值 |
| **采样率** | ADC 对模拟信号进行采样的频率 |
| **总采样率** | ADC 在给定配置下的总吞吐率 |
| **单通道有效采样率** | 考虑 MUX 开销后的单通道实际采样率 |
| **表征模式** | 连续记录器件上升或衰减过程的采样方式 |
| **稳态测量模式** | 等待后可配置时间后采集若干点求平均再估计光功率的方式 |
| **标准反向传播** | 传统梯度下降 CNN 训练方法 |
| **类脑更新规则** | 受生物可塑性启发的参数更新方法（候选方向） |
| **器件模型驱动训练** | 将标准图像按器件响应模型转换为电导/电流表示后再训练 |
| **FPGA 数字推理** | 在 FPGA 上使用定点数执行标准数字 CNN 前向计算 |
| **ONN** | 光学神经网络（Optical Neural Network）——本项目课题名称 |
