# 项目范围基线

> **本文档是项目范围的唯一事实源。** 其他文档链接至此，不各自重新定义项目目标。

---

## 一句话定义

> 本项目当前包含两个独立交付方向：一是为 4×4 光学突触阵列实现可配置采样率、支持长时间监测的多通道外围采集系统；二是在 Cyclone IV FPGA 上部署接受 28×28 手写数字输入的数字 CNN 推理模型。两部分当前不要求进行物理端到端连接。

---

## 固定交付物 A：4×4 外围采集系统

为当前 4×4 光学突触器件设计传感器外围电路，实现器件表征和数据采集。

### 交付物清单

- [ ] 外围电路设计（保护/偏置/通道选择/读出/模数转换）
- [ ] 安全读出方案（限流、限压、上电顺序）
- [ ] 16 通道选择或可验证的通道扫描
- [ ] 多档采样能力（快速瞬态 / 常规曲线 / 长时监测）
- [ ] 高频瞬态捕获能力（最快特征内有足够采样点）
- [ ] 长时连续监测（秒至小时级）
- [ ] 带时间戳的原始 ADC 数字序列保存
- [ ] 标定后的电压/电流换算
- [ ] 条件满足时（读出偏置和转换关系明确后）电导换算
- [ ] PC 端数据保存和曲线显示
- [ ] 至少一组可验证的器件响应记录

### 验收原则

- 采集到的数据首先是 ADC 原始码、电压或电流；电导为派生量
- "高频采样"是能力要求，不等于所有实验始终以最高采样率运行
- 具体采样率由器件最快有效响应、模拟带宽、MUX 建立时间、ADC 吞吐率和数据传输能力派生
- 不预设 16 路同时采样、不预设控制器一定是 FPGA、不预设输出一定是电导

## 固定交付物 B：28×28 CNN FPGA 数字推理

使用标准 28×28 手写数字输入，在 Python 中完成 CNN 训练和定点化，在 FPGA 上完成前向推理。

### 交付物清单

- [ ] Python 浮点 CNN 训练流水线（含基线准确率）
- [ ] 定点/量化参考模型（与浮点比对）
- [ ] 权重、偏置和测试数据导出
- [ ] Verilog 定点 CNN 前向推理实现
- [ ] Testbench 和仿真验证
- [ ] Python 与 RTL bit-accurate 一致性比对
- [ ] FPGA 综合和资源/频率报告
- [ ] 28×28 手写数字推理结果（0–9 分类）

### 验收原则

- 输入来自数字数据源（testbench、ROM、PC 传输等），不来自 4×4 采集电路
- 第一版必须建立普通 CNN 基线，自定义优化器不能阻塞 FPGA 推理链路
- FPGA 执行普通数字前向计算，物理光学器件不参与 FPGA 上的乘加
- 硬件平台为小梅哥 AC620（Cyclone IV），工具为 Quartus + ModelSim/Questa
- 4×4 阵列不是 28×28 CNN 的直接输入

## 辅助研究任务 C：器件曲线建模与优化器探索

不阻塞 A/B 交付的独立研究任务，使用课题组论文数据。

- [ ] 课题组论文器件曲线整理和拟合（区分光响应曲线与权重更新曲线）
- [ ] 复现 `W = G+ − G−` 差分电导更新方法（参考外部论文 P3）
- [ ] 将器件曲线方法推广到 CNN（非单层感知机）
- [ ] 比较普通 Adam 与器件曲线优化器效果
- [ ] 未来用 4×4 实测曲线替换论文数据
- [ ] 探索 4×4 时间曲线特征分类可行性

### 辅助地位说明

- 器件曲线处理属于 Python 训练/建模问题，不改变 FPGA 推理硬件的基本性质
- 普通 Adam CNN 必须作为对照基线
- 不得预设器件曲线优化器一定优于 Adam
- FPGA 只部署最终数字等效权重，不在推理时重放器件曲线

## 当前明确不做

以下内容不在当前项目阶段范围内，如保留在文档中只能标记为**未来扩展**、**论文参考**或**非本阶段交付**：

- 4×4 采集电路直接连接 FPGA CNN 输入
- 4×4 阵列直接接收 28×28 MNIST 图像
- 计算阵列外围电路（非传感器读出电路）
- 阵列内向量-矩阵乘法（VMM）
- 物理器件存储 CNN 权重
- 在线训练或权重更新
- 脉冲神经网络（SNN）
- 更大阵列（>4×4）
- 完整端到端光电识别系统
- 证明自定义优化器优于 Adam
- 器件曲线特征直接作为 28×28 CNN 输入

---

## 两条主线的离线弱联系

二者只可能在算法层形成离线弱联系：

```
课题组论文曲线 / 未来 4×4 实测曲线
→ Python 器件曲线模型或参数更新方法
→ 得到数字 CNN 权重
→ FPGA 部署最终数字权重
```

这不是实时硬件接口，不改变 FPGA 推理的数字性质。

## 术语表

| 术语 | 定义 |
|------|------|
| **光学突触器件** | 具有光响应和记忆可塑性的光电器件，当前为 4×4 阵列 |
| **传感器外围电路** | 用于器件信号读出的前端电路（保护/偏置/通道选择/放大/模数转换），非计算阵列外围 |
| **器件表征** | 通过受控激励测量器件的电学和光学响应特性 |
| **采样率** | 模数转换器对模拟信号进行采样的频率 |
| **总采样率** | ADC 在给定配置下的总吞吐率，受 ADC 自身规格和数字接口限制 |
| **单通道有效采样率** | 总采样率除以启用通道数（考虑 MUX 建立时间和切换开销后的实际值） |
| **光响应时间曲线** | 器件输出（电流/电压/电导）随时间变化的曲线，用于表征和特征提取 |
| **权重更新曲线** | 器件电导随增强/抑制脉冲次数变化的曲线，用于参数更新或权重约束 |
| **器件曲线优化器** | 在梯度下降中引入器件实测/拟合曲线约束的参数更新方法 |
| **FPGA 数字推理** | 在 FPGA 上使用定点数执行标准数字 CNN 前向计算 |
| **物理计算阵列** | 利用物理器件（如忆阻器阵列）本身执行模拟矩阵运算的架构 |
| **ONN** | 光学神经网络（Optical Neural Network）——本项目课题名称，涵盖光电结合的研究方向 |
