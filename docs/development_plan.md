## M0：课题定义明确

> 状态：⚡ 进行中

本阶段目标是将课题从"大致知道方向"推进到"清楚要做什么以及怎么做"。
**M0 完成前，不启动任何具体实现工作。**

| 任务 | 说明 | 状态 |
|------|------|------|
| 充分阅读论文，理解光学器件输出特性与信号形式 | 包括课题组论文和外部参考论文，明确光电器件输出信号的空间/时间特性 | ⬜ 待开始 |
| 明确系统输入到底是什么 | 输入是静态图像？脉冲序列？连续模拟信号？需经过怎样的采样/编码才能送入网络？ | ⬜ 待开始 |
| 明确网络输入的数据形式 | 输入张量的维度？时间维度如何处理？是单帧处理还是多帧累积？ | ⬜ 待开始 |
| 明确光学器件在系统中的职责 | 只做传感器？还是参与计算？如何使用课题组提供的特性参数？ | ⬜ 待开始 |
| 明确现有硬件条件 | AC620 FPGA 具体型号、逻辑资源、可用外设 | ⬜ 待开始 |
| 明确暑假阶段目标 | 确定到暑假结束前可验证的最小系统是什么 | ⬜ 待开始 |
| 形成统一的系统框架文档 | 将上述所有结论整理到对应文档中 | ⬜ 待开始 |

**验收标准**：
- 上述所有问题有明确结论或确定的验证计划
- 形成各方认可的系统框架文档
- 可以进入下一阶段的具体实现
