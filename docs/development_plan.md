## A 路线：光电突触阵列信号采集与光功率重建

### M1-A：器件测量方案和前端采集原型

**目标**：确认器件基本电气行为与持续特性，搭建单通道/少通道前端采集原型，验证 FPGA 采样和缓存结构。

当前阵列尚未制作完成，M1-A 允许使用以下替代数据源验证 FPGA 数字处理结构：
- 信号发生器输出模拟器件信号
- 预先录制的模拟数据
- 可配置 ADC 数据源
- 单通道或少通道原型

| 交付物 | 验收标准 |
|-------|---------|
| 器件基本电气参数确认（pinout、暗电流、偏置条件） | 老师/研究生确认并文档化 |
| 单通道安全读出电路设计 | 可安全读取至少 1 个单元的输出 |
| 基本 ADC 采样验证 | ADC 输出可被 FPGA 读取 |
| FPGA 采样控制与缓存原型 | FPGA 可配置采样参数并记录数据 |
| 可配置采样参数（sample_period, start_delay, sample_count, average_count） | 参数可通过接口修改 |
| 表征模式和稳态测量模式原型 | 两种模式均可触发并记录结果 |
| 多次采样 / 动态曲线记录原型 | 支持多时间点采样与恢复条件记录 |
| 原始 ADC 数据保留与导出 | 数据文件包含原始码值和时间戳 |

**依赖**：
- 器件 pinout 和安全规格（阻塞通电，不阻塞原型验证）
- ADC 选型

### M2-A：4×4 阵列标定与光功率模型

**目标**：使用实物 4×4 阵列采集响应数据，在 PC 端建立光功率经验模型。

| 交付物 | 验收标准 |
|-------|---------|
| 阵列暗态基线数据 | 16 单元暗态值记录 |
| 已知光功率下的响应数据集 | 多功率级、至少一组重复 |
| 器件动态响应分析（上升/衰减/稳态/恢复条件） | 时间常数可提取 |
| 光功率经验模型（含模型参数） | 拟合误差可接受范围内，限定测量协议 |
| 评估是否需要逐像素标定 | 结论明确并文档化 |
| 供 FPGA 使用的参数/LUT/分段线性映射 | 格式清晰，FPGA 可加载 |

**依赖**：M1-A

### M3-A：FPGA 采样、归一化和光功率映射

**目标**：在 FPGA 上实现完整数据链路——从 ADC 采样到协议限定下的光功率估计与 4×4 矩阵输出。

| 交付物 | 验收标准 |
|-------|---------|
| 零点/增益校正 RTL 实现 | 校正结果与 PC 参考一致 |
| 响应归一化 RTL 实现 | 归一化结果与 PC 参考一致 |
| 光功率映射（LUT/分段线性/定点多项式，协议限定） | 映射结果与 PC 模型一致 |
| 4×4 光功率矩阵输出 | 可读格式（仿真/传输/显示） |
| 带时间戳多次采样序列保留与导出 | 支持动态曲线记录 |
| FPGA 资源占用报告 | LE/M9K 使用率文档化 |
| 原始 ADC 数据导出功能 | 保留原始值供标定迭代 |

**依赖**：M2-A（模型参数）

### M4-A：路线 A 性能验证

| 交付物 | 验收标准 |
|-------|---------|
| 不同光功率下的 4×4 矩阵输出 | 输出稳定且可重复 |
| 标定精度评估 | 光功率估计误差文档化 |
| 系统功耗评估 | 器件+前端+ADC+FPGA 总能耗 |
| 项目总结报告（路线 A 部分） | 含经验教训和改进方向 |

**依赖**：M3-A
