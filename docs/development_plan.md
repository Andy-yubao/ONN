## A 路线：光电突触阵列信号采集与光功率重建

### M1-A：器件测量方案和前端采集原型

**目标**：确认器件基本电气行为，搭建单通道/少通道前端采集原型，验证 FPGA 采样和缓存结构。

当前阵列尚未制作完成，M1-A 允许使用以下替代数据源验证 FPGA 数字处理结构：
- 信号发生器输出模拟器件信号
- 预先录制的模拟数据
- 可配置 ADC 数据源
- 单通道或少通道原型

| 交付物 | 验收标准 |
|-------|---------|
| 器件基本电气参数确认（pinout、暗电流、偏置条件） | 老师/研究生确认并文档化 |
| 单通道安全读出电路设计 | 可安全读取至少 1 个单元的输出 |
| 基本 ADC 采样验证 | ADC 输出可被 FPGA 读取 |
| FPGA 采样控制与缓存原型 | FPGA 可配置采样参数并记录数据 |
| 可配置采样参数（sample_period, start_delay, sample_count, average_count） | 参数可通过接口修改 |
| 表征模式和稳态测量模式原型 | 两种模式均可触发并记录结果 |
| 原始 ADC 数据保留与导出 | 数据文件包含原始码值和时间戳 |

**依赖**：
- 器件 pinout 和安全规格（阻塞通电，不阻塞原型验证）
- ADC 选型

### M2-A：4×4 阵列标定与光功率模型

**目标**：使用实物 4×4 阵列采集响应数据，在 PC 端建立光功率经验模型。

| 交付物 | 验收标准 |
|-------|---------|
| 阵列暗态基线数据 | 16 单元暗态值记录 |
| 已知光功率下的响应数据集 | 多功率级、至少一组重复 |
| 器件动态响应分析（上升/衰减/稳态） | 时间常数可提取 |
| 光功率经验模型（含模型参数） | 拟合误差可接受范围内 |
| 评估是否需要逐像素标定 | 结论明确并文档化 |
| 供 FPGA 使用的参数/LUT/分段线性映射 | 格式清晰，FPGA 可加载 |

**依赖**：M1-A

### M3-A：FPGA 采样、归一化和光功率映射

**目标**：在 FPGA 上实现完整数据链路——从 ADC 采样到 4×4 光功率矩阵输出。

| 交付物 | 验收标准 |
|-------|---------|
| 零点/增益校正 RTL 实现 | 校正结果与 PC 参考一致 |
| 响应归一化 RTL 实现 | 归一化结果与 PC 参考一致 |
| 光功率映射（LUT/分段线性/定点多项式） | 映射结果与 PC 模型一致 |
| 4×4 光功率矩阵输出 | 可读格式（仿真/传输/显示） |
| FPGA 资源占用报告 | LE/M9K 使用率文档化 |
| 原始 ADC 数据导出功能 | 保留原始值供标定迭代 |

**依赖**：M2-A（模型参数）

### M4-A：路线 A 性能验证

| 交付物 | 验收标准 |
|-------|---------|
| 不同光功率下的 4×4 矩阵输出 | 输出稳定且可重复 |
| 标定精度评估 | 光功率估计误差文档化 |
| 系统功耗评估 | 器件+前端+ADC+FPGA 总能耗 |
| 项目总结报告（路线 A 部分） | 含经验教训和改进方向 |

**依赖**：M3-A

## B 路线：类脑 CNN 训练研究与 FPGA 推理部署

### M1-B：MNIST 软件基线与 Tiny-ResNet 基线

**目标**：建立标准反向传播训练流水线，实现浮点 CNN 基线。（完成状态：✅ **M1-B 已完成**，详见 [model_architecture.md](model_architecture.md) 和 [实验结果](../experiments/model_baselines/m1_baselines/README.md)。）

| 交付物 | 验收标准 | 状态 |
|-------|---------|:---:|
| Python 训练流水线（PyTorch） | 可复现训练 + 验证流程 | ✅ |
| Tiny-ResNet/浅层残差 CNN 实现 | 候选架构浮点准确率可报告 | ✅ |
| 普通 CNN/LeNet 对照基线 | 对照模型准确率可报告 | ✅ |
| 网络结构文档化 | 层数、核大小、通道数、参数量 | ✅ |
| 权重/偏置导出脚本 | 导出格式清晰 | 📋 待后续 |

**依赖**：无（可立即启动）

### M1-B.1：基线实验审计与可复现性加固

**目标**：修复 M1-B 基线中的实验与工具问题，使训练框架可作为后续类脑学习规则实验的可信基础。（完成状态：✅ **M1-B.1 已完成**，详见 [实验结果](../experiments/model_baselines/m1_baseline_audit/README.md)。）

| 交付物 | 验收标准 | 状态 |
|-------|---------|:---:|
| 活动分析改为模块最终输出（post-activation） | ReLU/BasicBlock 最终输出，非 Conv 原始输出 | ✅ |
| 活动统计字段名修正 | active_ratio / near_zero_ratio，非 nonzero_ratio / zero_ratio | ✅ |
| sample_count 和 batch_count 正确 | 样本级而非 batch 级计数，不完整 batch 加权 | ✅ |
| Smoke test 真正限制 batch 数 | 最多2个训练batch + 2个验证batch | ✅ |
| pytest 不依赖 MNIST 下载 | 合成数据注入，网络不可用时仍可测试 | ✅ |
| Deterministic 模式开关 | config 中 deterministic 字段，影响 cudNN 和 RNG | ✅ |
| 断点续训完整状态恢复 | 含 scheduler、scaler、RNG、history | ✅ |
| 旧检查点兼容 | Tiny-ResNet 重构后仍可 strict 加载旧权重 | ✅ |
| 多种子基线（seeds 42/43/44） | mean±std 准确率报告 | ✅ |
| 文档修正 | FPGA 表述、活动结论、损失表述 | ✅ |

**依赖**：M1-B

### M2-B：类脑更新规则最小实验

**目标**：在基线之上实现至少一种候选类脑更新规则，形成对照结果。

| 交付物 | 验收标准 |
|-------|---------|
| 至少一种候选类脑规则实现（Hebbian/Oja/三因素等） | 训练可收敛 |
| 类脑规则与标准 BP 的对比结果 | 准确率/收敛速度/稀疏度对比表 |
| 若类脑方法不改善指标，诚实报告 | 结果文档化，不强制要求改善 |
| 实验代码和超参数文档化 | 可复现实验 |

**依赖**：M1-B

### M3-B：模型量化与 FPGA CNN 推理

**目标**：完成量化方案确定和参数导出，在 FPGA 上实现定点前向推理。

| 交付物 | 验收标准 |
|-------|---------|
| 定点/量化方案（位宽、策略） | 与浮点基线准确率降幅可接受 |
| 量化权重/偏置导出 | 格式供 FPGA 加载 |
| 定点参考模型（逐层中间值） | 供 RTL bit-accurate 比对 |
| FPGA CNN 前向推理 RTL | 仿真通过 |
| RTL 与 Python bit-accurate 比对 | 逐层一致 |
| FPGA 综合报告（资源/频率） | LE/M9K/DSP 使用率 < 90% |
| 至少 1000 张测试图像推理结果 | 结果可复现 |

**依赖**：M2-B（类脑实验）+ M1-B（基线）

### M4-B：路线 B 性能验证

| 交付物 | 验收标准 |
|-------|---------|
| 硬件推理准确率报告 | 与软件定点基线一致 |
| 推理延迟（时钟周期数） | 文档化 |
| 资源占用详细报告 | 按模块分解 |
| 评估权重量化 | 含准确率降幅、收敛速度、稀疏度等 |
| 项目总结报告（路线 B 部分） | 含经验教训和改进方向 |

**依赖**：M3-B
