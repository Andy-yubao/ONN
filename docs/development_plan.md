## C 轨：辅助器件曲线建模（不阻塞 A/B）

> C 轨任务可在 A/B 轨进行中间步启动，不进入 A/B 的关键路径。

| 编号 | 任务 | 依赖 | 优先级 |
|------|------|------|--------|
| C1 | 论文曲线整理与拟合 | 无 | P2 |
| C2 | 复现 P3 差分电导更新方法 | C1 | P2 |
| C3 | 推广到 CNN 并与 Adam 对照 | C2 + B1 | P2 |
| C4 | 用未来 4×4 实测曲线替换论文数据 | A4 + C3 | P3 |

**辅助地位说明**：
- 器件曲线处理是 Python 训练/建模问题，不改变 FPGA 推理的数字性质
- 普通 Adam CNN 是 FPGA 推理基线和器件曲线方法的对照，不是多余任务
- 不得预设器件曲线优化器一定优于 Adam
