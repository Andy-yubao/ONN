# 待确认问题

> 本文档集中记录所有尚未确定的问题。随着项目推进，已确认的问题移入对应文档，新增问题随时补充。

## 核心问题：系统输入与网络输入形式

- [ ] **光学器件的输出信号到底是什么形式？**（电流脉冲？连续模拟信号？光强变化？）
- [ ] **信号的时间特性是怎样的？** 是瞬间响应还是有一个时间过程？脉冲宽度是多少？
- [ ] **网络的输入该如何构造？** 既然不是一瞬间的电信号决定，是要累积一段时间内的信号吗？
- [ ] **时间维度的数据怎么处理？** 是把一段时间的数据直接拼接成更高维的张量，还是需要特殊的编码方式（如频率编码、脉冲编码、时间编码）？
- [ ] **输入数据是否需要特殊的预处理？** 滤波、去噪、归一化？是否需要根据器件特性添加仿真噪声？
- [ ] **三个通道（如 RGB）如何对应到器件输出？** 是一个器件对应一个通道，还是单个器件通过时间复用输出多通道数据？
- [ ] **MNIST 是单通道灰度图，而最终任务是三通道，这之间的差异如何处理？**
- [ ] **数据集最终用什么？** MNIST？CIFAR？还是自建紫外事件数据集？
