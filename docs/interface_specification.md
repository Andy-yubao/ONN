# 接口规格

> **重要提示**：接口按两条独立路线定义。A 类为光电突触阵列采集与光功率重建接口，B 类为 CNN 训练与 FPGA 推理接口。两组之间不存在当前阶段的正式实时系统接口，但允许离线算法耦合（路线 A 的响应模型为路线 B 的训练数据变换提供依据）。
>
> 本文档定义当前能够确定的**逻辑数据形式**。具体电气参数和物理接口待器件实测和选型后补充。

---

## A 类接口：光电突触阵列信号采集与光功率重建

### 数据分层定义

路线 A 的数据处理链路产生以下层次的数据，各层次对应不同的物理/逻辑含义：

```
原始 ADC 码值 ─→ 校正后响应 ─→ 归一化响应 ─→ 光功率估计值（协议限定）
(raw_adc)     (calibrated)   (normalized)   (optical_power)
```

### A0 原始 ADC 数据（带时间戳的多次采样序列）

```
raw_adc[channel][time]
```

| 项 | 说明 |
|----|------|
| `channel` | 0…15，对应 4×4 阵列的 16 个单元 |
| `time` | 0…sample_count-1，时间序列索引（多次采样 / 动态曲线记录） |
| 时间戳 | 每采样点带时间戳（相对或绝对时间） |
| 数据类型 | 整型（实际位宽待 ADC 选型） |
| 物理含义 | ADC 量化后的数字码值，未经任何校正 |
| 状态信息 | 采样时应记录前序光照/偏置历史、恢复时间、温度、采样时刻或统计窗口 |

### A1 校正后响应

```
calibrated_response[channel]
```

| 项 | 说明 |
|----|------|
| 生成方式 | 原始 ADC 值经零点/增益校正 |
| 物理含义 | 扣除暗电流/偏置后的相对响应值（可为整型或定点数） |
| 定点格式 | TBD—待校正方案确定 |

### A2 归一化响应

```
normalized_response[channel]
```

| 项 | 说明 |
|----|------|
| 生成方式 | 校正后响应经归一化处理 |
| 物理含义 | 无量纲相对响应，范围通常映射到 [0, 1] 或 [-1, 1] |
| 定点格式 | TBD—待归一化方案确定 |

### A3 光功率估计值（协议限定）

```
optical_power[channel]     →  optical_power[4][4]
```

| 项 | 说明 |
|----|------|
| 生成方式 | 在明确测量协议下，归一化响应通过已标定经验模型/LUT 映射为光功率 |
| 协议限定 | 波长、偏置、初始状态或恢复条件、光照历史、等待时间、采样时刻或统计窗口、温度、特征选择、标定范围、单调性/可逆性 |
| 物理含义 | 对应通道在标定范围内的光功率估计值（单位：µW 或相对功率） |
| 数据格式 | 定点数或整型（缩放后的功率值） |
| 边界 | `4×4` 光功率矩阵是受条件约束的目标输出，不覆盖原始时间序列，不作无条件唯一反演 |

### A4 光源 → 器件

| 接口 | 说明 | 状态 |
|------|------|------|
| 光源类型 | 激光（波长固定） | 已确认 |
| 波长 | 固定波长（当前不考虑波长-功率耦合） | 已确认 |
| 光功率 | 从 µW 级开始，逐步增加 | 待实验 |
| 光斑覆盖 | 覆盖单个单元或全阵列 | 待实验 |
| 耦合方式 | 光纤/自由空间/显微物镜 | 待实验 |

### A5 器件 → 偏置/读出

| 接口 | 说明 | 状态 |
|------|------|------|
| pinout | 引脚号 → 功能映射 | 🔴 **阻塞性待确认** |
| 端口方向 | 每端口输入/输出/双向 | 🔴 **阻塞性待确认** |
| 偏置条件 | 推荐电压/电流和绝对最大值 | 🔴 **阻塞性待确认** |
| 输出类型 | 电流/电压/电荷 | 待确认 |
| 输出范围 | 最小值、最大值、暗值 | 待确认 |
| 阵列拓扑 | 独立/交叉/晶体管/复用 | 待确认 |
| 公共端/参考端 | 共享地或独立地 | 待确认 |
| 持续特性 | 稳态时间（会议估计 20 s–1 min）、恢复条件、状态依赖 | 待实验（未实测） |

### A6 模拟前端 → ADC

| 接口 | 说明 | 状态 |
|------|------|------|
| 调理方式 | TIA/放大器/滤波（候选方案） | 待设计（器件参数确认后） |
| 偏置方案 | 可控或可配置偏置 | 已确认（需要偏置） |
| ADC 位宽 | 满足动态范围需求 | 待设计（资源评估） |
| ADC 采样率 | 由最快特征派生 | 待设计（派生值） |
| ADC 输入范围 | 与调理后信号匹配 | 待确认 |
| ADC 输入类型 | 单端/差分 | 待设计（选型） |
| ADC 数字接口 | SPI/并行/其它 | 待设计（选型） |
| 模拟通道数 | 1–16（是否复用待设计权衡） | 待设计 |

### A7 采样配置参数

```
sample_period    采样周期（控制 ADC 采样间隔）
start_delay      光照或触发后的等待时间（用于稳态测量模式）
sample_count     每轮采样数量（多次采样）
average_count    稳态平均窗口长度（用于稳态测量模式）
```

这些参数在 FPGA 中可配置。具体数值范围和数据位宽待采样率确定后定义。为支持持续特性表征，还需记录：前序光照/偏置历史、恢复/预处理时间、是否达到稳态、是否出现不可逆变化。

### A8 采集控制器 → PC

| 接口 | 说明 | 状态 |
|------|------|------|
| 传输方式 | UART/USB/Ethernet | 待设计 |
| 协议 | 自定义/标准 | 待设计 |
| 数据内容 | 原始 ADC 值 + 校正/归一化/光功率结果 + 时间戳 + 采样状态 | 已确认 |

## B 类接口：类脑 CNN 训练研究与 FPGA 推理部署

### B0 数据定义（已完成基线的冻结数值标准）

```
input_image[1][28][28]    单通道 28×28 灰度图像（输入）
quantized_weight          INT8 signed，[-127,127]，zero_point=0
quantized_activation      UINT8，[0,255]，zero_point=0（ReLU 后）
accumulator               INT32 signed（无溢出/回绕）
gap_q                     UINT8（整数÷49，round-half-away-from-zero）
class_score[10]           INT32 logits
predicted_class           argmax（tie 选较小类别号，0–9）
```

> 冻结数值标准：`Int8Reference`（`model/onn_model/int8_reference.py`）+ `candidate_quant_config.json`（方案 A，per-tensor 权重）。详见 [data_format.md](../fpga/baseline_cnn/docs/data_format.md)。

### B1 Python 训练输出 → FPGA 输入（已实现）

| 接口 | 说明 | 状态 |
|------|------|------|
| 图像数据 | 28×28 灰度，MNIST 归一化（0.1307/0.3081） | 已实现 |
| 权重格式 | INT8 signed，per-tensor scale | 已实现 |
| 偏置格式 | INT32（量化进累加器） | 已实现 |
| 层参数 | 层类型、核大小、步长、填充 | 已实现（冻结 BaselineCNN 结构） |
| 导出格式 | `.mem` / `.mif` / `.vh` 参数（`fpga/baseline_cnn/params/`，含 SHA256 checksums） | 已实现 |
| 输入方式 | 当前固定 digit8 片上 ROM（板级自检）；外部输入/UART 未实现 | 部分完成 |

### B2 FPGA 输出（已实现）

| 接口 | 说明 | 状态 |
|------|------|------|
| 分类结果 | 0–9 数字（prediction，done 时有效并保持） | 已实现 |
| 调试输出 | 中间层值（仿真 trace 节点） | 已实现（仿真） |
| 结果显示 | 板级 LED 心跳 / PASS-FAIL 动画 | 已实现（固定 digit8 自检） |
| 外部结果输出 | 数码管/UART | 待设计 |

### B3 Bit-accurate 比对（已实现）

| 接口 | 说明 | 状态 |
|------|------|------|
| Python 参考 | 纯整数参考模型的逐层中间值 | 已实现 |
| RTL 输出 | 仿真/硬件输出（11 个节点） | 已实现 |
| 比较方式 | 逐层逐位一致比对 | 已实现（Questa 黄金向量 + Python 契约测试） |

### B4 器件模型驱动数据变换（新增方向，待设计）

| 接口 | 说明 | 状态 |
|------|------|------|
| 输入图像 | 标准 RGB 或其他图像 | 待实验（数据集选择 TBD） |
| 变换模型 | 器件响应模型（论文参数或实测参数）→ 电导/电流表示 | 待实验（矩阵尺寸/编码 TBD） |
| 训练数据 | 转换后的电导/电流表示数据集 | 待实验 |
| 时序编码 | 多次采样与时序特征编码 | 待设计（TBD） |
