# 接口规格

> **重要提示**：接口按两条独立路线定义。A 类为光电突触阵列采集与光功率重建接口，B 类为 CNN 训练与 FPGA 推理接口。两组之间不存在当前阶段的正式系统接口。
>
> 本文档定义当前能够确定的**逻辑数据形式**。具体电气参数和物理接口待器件实测和选型后补充。

---

## A 类接口：光电突触阵列信号采集与光功率重建

### 数据分层定义

路线 A 的数据处理链路产生以下层次的数据，各层次对应不同的物理/逻辑含义：

```
原始 ADC 码值 ─→ 校正后响应 ─→ 归一化响应 ─→ 光功率估计值
(raw_adc)     (calibrated)   (normalized)   (optical_power)
```

### A0 原始 ADC 数据

```
raw_adc[channel][time]
```

| 项 | 说明 |
|----|------|
| `channel` | 0…15，对应 4×4 阵列的 16 个单元 |
| `time` | 0…sample_count-1，时间序列索引 |
| 数据类型 | 整型（实际位宽待 ADC 选型） |
| 物理含义 | ADC 量化后的数字码值，未经任何校正 |

### A1 校正后响应

```
calibrated_response[channel]
```

| 项 | 说明 |
|----|------|
| 生成方式 | 原始 ADC 值经零点/增益校正 |
| 物理含义 | 扣除暗电流/偏置后的相对响应值（可为整型或定点数） |
| 定点格式 | TBD—待校正方案确定 |

### A2 归一化响应

```
normalized_response[channel]
```

| 项 | 说明 |
|----|------|
| 生成方式 | 校正后响应经归一化处理 |
| 物理含义 | 无量纲相对响应，范围通常映射到 [0, 1] 或 [-1, 1] |
| 定点格式 | TBD—待归一化方案确定 |

### A3 光功率估计值

```
optical_power[channel]     →  optical_power[4][4]
```

| 项 | 说明 |
|----|------|
| 生成方式 | 归一化响应通过已标定经验模型/LUT 映射为光功率 |
| 物理含义 | 对应通道的实际光功率估计值（单位：µW 或相对功率） |
| 数据格式 | 定点数或整型（缩放后的功率值） |

### A4 光源 → 器件

| 接口 | 说明 | 状态 |
|------|------|------|
| 光源类型 | 激光（波长固定） | 已确认 |
| 波长 | 固定波长（当前不考虑波长-功率耦合） | 已确认 |
| 光功率 | 从 µW 级开始，逐步增加 | TBD—待实验 |
| 光斑覆盖 | 覆盖单个单元或全阵列 | TBD—待实验 |
| 耦合方式 | 光纤/自由空间/显微物镜 | TBD—待实验条件 |

### A5 器件 → 偏置/读出

| 接口 | 说明 | 状态 |
|------|------|------|
| pinout | 引脚号 → 功能映射 | 🔴 **阻塞性待确认** |
| 端口方向 | 每端口输入/输出/双向 | 🔴 **阻塞性待确认** |
| 偏置条件 | 推荐电压/电流和绝对最大值 | 🔴 **阻塞性待确认** |
| 输出类型 | 电流/电压/电荷 | TBD—待确认 |
| 输出范围 | 最小值、最大值、暗值 | TBD—待确认 |
| 阵列拓扑 | 独立/交叉/晶体管/复用 | TBD—待确认 |
| 公共端/参考端 | 共享地或独立地 | TBD—待确认 |

### A6 模拟前端 → ADC

| 接口 | 说明 | 状态 |
|------|------|------|
| 调理方式 | TIA/放大器/滤波（候选方案） | TBD—待器件参数确认 |
| 偏置方案 | 可控或可配置偏置 | 架构已确认（需要偏置） |
| ADC 位宽 | 满足动态范围需求 | TBD—待资源评估 |
| ADC 采样率 | 由最快特征派生 | TBD—派生值 |
| ADC 输入范围 | 与调理后信号匹配 | TBD—待确认 |
| ADC 输入类型 | 单端/差分 | TBD—待选型 |
| ADC 数字接口 | SPI/并行/其它 | TBD—待选型 |
| 模拟通道数 | 1–16（是否复用待设计权衡） | TBD—待设计选择 |

### A7 采样配置参数

```
sample_period    采样周期（控制 ADC 采样间隔）
start_delay      光照或触发后的等待时间（用于稳态测量模式）
sample_count     每轮采样数量
average_count    稳态平均窗口长度（用于稳态测量模式）
```

这些参数在 FPGA 中可配置。具体数值范围和数据位宽待采样率确定后定义。

### A8 采集控制器 → PC

| 接口 | 说明 | 状态 |
|------|------|------|
| 传输方式 | UART/USB/Ethernet | TBD—待设计选择 |
| 协议 | 自定义/标准 | TBD—待设计选择 |
| 数据内容 | 原始 ADC 值 + 校正/归一化/光功率结果 | 架构已确认 |

## B 类接口：类脑 CNN 训练研究与 FPGA 推理部署

### B0 数据定义

```
input_image[1][28][28]    单通道 28×28 灰度图像（输入）
quantized_weight          量化后的定点权重
quantized_activation      量化后的定点激活值
class_score[10]           10 类得分（logits 或 softmax 输出）
predicted_class           最终分类结果（argmax，0–9）
```

> 具体定点格式（整数位宽、小数位宽、是否对称量化）待量化实验和 FPGA 资源评估后确定。

### B1 Python 训练输出 → FPGA 输入

| 接口 | 说明 | 状态 |
|------|------|------|
| 图像数据 | 28×28 灰度，归一化方式 | TBD—待训练启动确认 |
| 权重格式 | 定点数（位宽、整数/小数位） | TBD—待量化实验 |
| 偏置格式 | 定点数 | TBD—待量化实验 |
| 层参数 | 层类型、核大小、步长、填充 | TBD—待网络结构确认 |
| 导出格式 | 十六进制/MIF/COE 文件 | TBD—待格式定义 |
| 输入方式 | testbench / ROM / PC 传输 | TBD—待设计选择 |

### B2 FPGA 输出

| 接口 | 说明 | 状态 |
|------|------|------|
| 分类结果 | 0–9 数字 | 架构已确认 |
| 调试输出 | 中间层值/softmax/logits | TBD—待设计 |
| 结果显示 | 数码管/UART/仿真波形 | TBD—待设计选择 |

### B3 Bit-accurate 比对

| 接口 | 说明 | 状态 |
|------|------|------|
| Python 参考 | 定点参考模型的逐层中间值 | 架构已确认 |
| RTL 输出 | 仿真/硬件输出 | 架构已确认 |
| 比较方式 | 逐层对比差值 | 架构已确认 |
