# 接口规格

> **重要提示**：接口按三组独立定义——A 类为采集系统接口，B 类为 FPGA 推理接口，C 类为器件曲线建模接口。A 和 B 之间不存在当前阶段的正式系统接口。
>
> **所有涉及器件的电气参数在官方确认前为 TBD（待确认）。禁止根据照片或推测填写参数。**

---

> ⚠ **当前不存在"4×4 外围电路 → FPGA CNN"的正式系统接口。** 以下 A、B 两组接口分别对应两条独立主线，它们之间没有直接的硬件信号连接。该接口不属于当前阶段交付。

---

## A 类接口：4×4 采集系统

### A1 光源 → 器件

| 接口 | 说明 | 状态 |
|------|------|------|
| 光源类型 | 激光/LED/可调谐光源 | ❓ 待确认 |
| 波长 | 根据器件响应范围选择 | ❓ 待确认 |
| 光功率密度 | 从 µW 级开始，逐步增加 | ❓ 待确认 |
| 光斑大小与位置 | 覆盖单个单元或全阵列 | ❓ 待确认 |
| 耦合方式 | 光纤/自由空间/显微物镜 | ❓ 待确认 |
| 脉冲调制 | 脉宽、占空比、序列 | ❓ 待确认 |

### A2 器件 → 保护/偏置/读出

| 接口 | 说明 | 状态 |
|------|------|------|
| pinout | 引脚号 → 功能映射 | ❓ **阻塞性待确认** |
| 端口方向 | 每端口输入/输出/双向 | ❓ **阻塞性待确认** |
| 偏置条件 | 推荐 V/I 和绝对最大值 | ❓ **阻塞性待确认** |
| 输出类型 | 电流/电压/电荷 | ❓ 待确认 |
| 输出范围 | 最小值、最大值、暗值 | ❓ 待确认 |
| 阵列拓扑 | 独立/交叉/晶体管/复用 | ❓ 待确认 |
| 公共端/参考端 | 共享地或独立地 | ❓ 待确认 |

### A3 通道选择

| 接口 | 说明 | 状态 |
|------|------|------|
| 通道数 | 最多 16（4×4） | ✅ 已确认 |
| 选择方式 | MUX 或其它 | ❓ 待确认 |
| MUX 建立时间 | 影响单通道有效采样率 | ❓ 待确认 |
| 通道间串扰 | 相邻/非相邻隔离 | ❓ 待确认 |

### A4 模拟前端 → ADC

| 接口 | 说明 | 状态 |
|------|------|------|
| 调理方式 | TIA/放大器/滤波 | ❓ 待器件参数确认 |
| ADC 输入范围 | 与调理后信号匹配 | ❓ 待确认 |
| ADC 位宽 | 满足动态范围需求 | ❓ 待确认 |
| ADC 采样率 | 由最快特征派生 | ❓ 派生值 |
| ADC 输入类型 | 单端/差分 | ❓ 待确认 |

### A5 ADC → 采集控制器

| 接口 | 说明 | 状态 |
|------|------|------|
| 数字接口 | SPI/并行/其它 | ❓ 待选型后确认 |
| 数据速率 | ADC 输出数据率 | ❓ 派生值 |
| 控制器类型 | FPGA/MCU/PC | ❓ 待确认 |

### A6 采集控制器 → PC

| 接口 | 说明 | 状态 |
|------|------|------|
| 传输方式 | UART/USB/Ethernet | ❓ 待确认 |
| 协议 | 自定义/标准 | ❓ 待确认 |
| 数据速率 | 满足采样数据吞吐 | ❓ 派生值 |

### A7 数据文件格式

建议包含以下字段（具体格式待定）：

```
timestamp, sample_index, row, column, channel,
adc_raw, voltage_V, current_A, conductance_S,
light_state, wavelength_nm, relative_intensity,
bias_V, sampling_mode, sampling_rate_Hz,
temperature_C, experiment_id
```

> `conductance_S` 字段保留，在无法换算时允许为空。

## B 类接口：Python → FPGA（训练到推理）

### B1 Python 训练输出 → FPGA 输入

| 接口 | 说明 | 状态 |
|------|------|------|
| 图像数据 | 28×28 灰度，归一化方式 | 待 B 轨启动确认 |
| 权重格式 | 定点数（位宽、整数/小数位） | 待 B 轨启动确认 |
| 偏置格式 | 定点数 | 待确认 |
| 层参数 | 层类型、核大小、步长、填充 | 待网络结构确认 |
| 导出格式 | 十六进制/MIF/COE 文件 | 待确认 |
| 输入方式 | testbench / ROM / PC 传输 | 待确认 |

### B2 FPGA 输出

| 接口 | 说明 | 状态 |
|------|------|------|
| 分类结果 | 0–9 数字 | 待实现 |
| 调试输出 | 中间层值/softmax/logits | 待实现 |
| 结果显示 | 数码管/UART/仿真波形 | 待确认 |

### B3 bit-accurate 比对

| 接口 | 说明 | 状态 |
|------|------|------|
| Python 参考 | 定点参考模型的逐层中间值 | 待实现 |
| RTL 输出 | 仿真/硬件输出 | 待实现 |
| 比较方式 | 逐层对比差值 | 待实现 |

## C 类接口：器件曲线 → Python 模型

> 这是离线数据处理接口，不是实时硬件接口。

| 接口 | 说明 | 状态 |
|------|------|------|
| 曲线来源 | 课题组论文数据 / 未来 4×4 实测 | 待整理 |
| 曲线种类 | 光响应时间曲线 / 权重更新曲线 | 待区分 |
| 数据格式 | 时间-电流/电导序列 | 待定义 |
| 单位 | 时间(s), 电流(A), 电导(S) | 待统一 |
| 拟合参数 | 峰值、稳态、衰减时间常数、非线性度 | 待提取 |
| 权重范围 | Gmin/Gmax、有效状态数 | 参考 P3 方法 |
| 增强/抑制非线性 | LTP/LTD 非线性参数 | 待拟合 |
| 噪声模型 | 读噪声、涨落、漂移 | 待确认 |
| 版本控制 | 曲线数据版本和来源标记 | 待建立 |
