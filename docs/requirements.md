# 需求文档

> **当前状态**：M0 已完成；路线 B 的 MNIST 数字基线（软件 → 量化 → 完整 RTL → 50 MHz STA → 固定 digit8 板级自检）已实现并通过仿真/综合/板级自检；路线 A 仍为架构规划。
> 需求按两条路线分组——A 组为光电突触阵列信号采集与光功率重建，B 组为类脑 CNN 训练研究与 FPGA 推理部署。两组无强制实时依赖，但允许离线算法耦合。
> 状态词统一为：已确认 / 已实现 / 已仿真验证 / 已综合验证 / 已板级自检 / 部分完成 / 待实验 / 待设计 / 阻塞 / 不在当前范围 / 已被替代。
