# 需求文档

> **当前状态**：M0 阶段，大部分需求待确认。

## 功能需求

### F1：信号输入与前端处理
> 说明：长期内无法直接操作光电突触器件实物，前端开发将基于器件特性仿真数据和信号模拟器进行。

| 编号 | 需求描述 | 优先级 | 状态 |
|------|---------|--------|------|
| F1.1 | 能够使用器件特性仿真数据替代实物器件信号进行系统开发 | P0 | 待确认 |
| F1.2 | 能够模拟器件的噪声、漂移等非理想特性用于训练和测试 | P0 | 待确认 |
| F1.3 | 能够处理来自信号模拟器或 ADC 的输入数据（具体格式待定） | P0 | 待确认 |
| F1.4 | 若需要外围电路，能够完成信号放大、滤波和模数转换 | P1 | 待系统框架明确 |
| F1.5 | 若需要向器件输出驱动信号，能够生成对应脉冲信号 | P2 | 待确认 |
