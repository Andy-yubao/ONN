# ⚠ 器件上电安全检查清单

> **目的**：在器件电气规格未知时，提供安全操作门槛。**本清单不能替代 datasheet。**
>
> **核心原则**：在获得官方 pinout、端口功能和绝对最大额定值前，**不连接电源、信号源或 FPGA GPIO**。
>
> 本文档服务于 **主线 A（4×4 传感器读出）**，不预设第一版需要计算阵列编程或 LTP/LTD 写脉冲。

---

## 第一步：确认规格（A1 完成前禁止通电）

- [ ] 官方 pinout 已确认
- [ ] 每端口功能（电源/地/信号输入/信号输出/双向/NC）已确认
- [ ] 绝对最大额定值（Vmax, Imax, Pmax）已确认
- [ ] 推荐工作条件（Vop, Iop, 时序）已确认
- [ ] 封装朝向和 1 号脚已确认
- [ ] 提供者已批准测试方案

> 以上任意一项未完成 → **停止，不要通电**

---

## 第二步：测试前确认（首次通电前）

- [ ] 1 号脚、地/公共端正确识别
- [ ] 所有电源、信号源的**限流设置**已配置（建议从 µA 级开始）
- [ ] **串联保护电阻**已接入
- [ ] 电源顺序已确认（如需要先施加偏置再照光等）
- [ ] 所有仪器已校准并在有效期内
- [ ] 老师和/或研究生已书面/当面确认测试方案
- [ ] 测试区域无其他危险因素

---

## 第三步：通电流程

### 3.1 暗态基线（无光照）

1. [ ] 环境光遮蔽，温度记录
2. [ ] 从提供者批准的**最低条件**开始（最低 Vds, 限流 µA 级）
3. [ ] 记录所有端口的**开路/短路检查**
4. [ ] 逐步升高偏置至推荐范围低端，记录 Ids/I-V
5. [ ] 保持观察 **1 分钟**，确认无异常漂移

**停止条件**（出现任一即立刻断电）：
- [ ] 电流超过限流值
- [ ] 电流持续上升不收敛
- [ ] 器件温度明显升高
- [ ] 可见物理损坏或异常
- [ ] 测量值不可重复

### 3.2 低功率光照响应

1. [ ] 从**最低光功率**开始（µW 级或更低）
2. [ ] 记录光照下的 Ids 变化
3. [ ] 确认光响应可重复（至少 3 次）
4. [ ] 确认断电后恢复暗态基线

### 3.3 脉冲/时间响应

1. [ ] 从宽脉冲（≥ 1 s，低功率）开始
2. [ ] 逐步缩短脉宽，观察 STP/LTP
3. [ ] 记录衰减曲线和时间常数
4. [ ] 确认器件状态可恢复
5. [ ] 记录是否达到稳态及所需时间（会议估计约 20 s–1 min，**待实测**）
6. [ ] 记录前序光照/偏置历史与恢复条件

**停止条件**（额外）：
- [ ] 出现不可逆的状态变化
- [ ] 衰减后无法回到暗态基线

---

## 第四步：采样档位验证

> 器件具有持续特性（状态依赖、记忆、慢衰减），表征应支持**多次采样与动态曲线记录**，不能依赖单点采样。

在采集系统具备多档采样能力后验证：

- [ ] **快速瞬态模式**：验证能否捕获预期最快特征（上升沿/下降沿/峰值）
- [ ] **常规曲线模式**：验证一般响应曲线的完整记录
- [ ] **长时监测模式**：验证连续记录的稳定性和数据完整性
- [ ] 确认**总采样率**与配置一致
- [ ] 确认**单通道有效采样率**（若使用 MUX）
- [ ] 测量 MUX 建立时间对采样的影响
- [ ] 确认 ADC 未饱和（信号在输入范围内）
- [ ] 确认模拟带宽足够（信号未明显衰减）
- [ ] 确认**原始 ADC 码**正确保存（未经不可逆处理）
- [ ] 验证时间戳准确性

---

## 第五步：记录要求

每次实验必须记录：

- [ ] 日期、时间、操作人
- [ ] 样品编号和单元编号
- [ ] 环境温度
- [ ] 光源波长、光功率密度、光斑大小
- [ ] 光源-器件距离
- [ ] 偏置电压/电流
- [ ] 脉冲宽度、占空比
- [ ] 采样模式（快速瞬态/常规/长时）
- [ ] 请求采样率和实际采样率
- [ ] 启用通道数和 MUX 配置
- [ ] ADC 位宽和模拟带宽设置
- [ ] 记录时长和总样本数
- [ ] 是否发生丢样
- [ ] 原始数据文件路径
- [ ] 标定数据文件路径
- [ ] 数据处理脚本版本
- [ ] 暗态基线值
- [ ] 前序光照/偏置历史、恢复/预处理时间
- [ ] 是否达到稳态、是否出现不可逆变化
- [ ] 异常现象描述
- [ ] 结论和下一步

## 安全操作规则（总结）

| 规则 | 说明 |
|------|------|
| **无规格不通电** | 无官方 pinout 和额定值 → 不通电 |
| **论文电压不安全** | P2 论文中的数值不构成安全值 |
| **从最低开始** | 限流 µA 级，电压从 0 开始步进 |
| **先暗态，再光照** | 先确认无光照时的电气行为 |
| **设停止条件** | 测试前定义好异常判断标准 |
| **首次须经确认** | 首次操作必须老师或研究生参与或书面批准 |
| **记录一切** | 环境、参数、数据、异常缺一不可 |
| **清单不替代 datasheet** | 本清单是安全补充，不能替代官方规格 |
| **先单通道，再多通道** | 先验证单通道安全，再扩展到多通道 |
