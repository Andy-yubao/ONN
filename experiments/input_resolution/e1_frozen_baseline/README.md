# 实验一：冻结 BaselineCNN 的输入分辨率兼容性

## 实验目的

评估已经完成 FPGA 部署的 BaselineCNN 在**不重新训练、不重新标定、不改变网络结构
和量化参数**的前提下，对较低有效空间分辨率输入的直接兼容能力。纯整数参考模型是
主要结论，BN 融合 FP32 和方案 A fake-quant 是诊断对照。

实验日期为 2026-08-19，代码基线为 `cee5aa3a838285291a54e14281078de5dc29bcb9`。
评测使用 CPU，软件环境为 Python 3.12.13、PyTorch 2.11.0+cu128、torchvision
0.26.0+cu128 和 Matplotlib 3.11.1。

- BN 融合 BaselineCNN：
  [`model/artifacts/baseline_cnn_seed43_bn_fused_fp32.pt`](../../../model/artifacts/baseline_cnn_seed43_bn_fused_fp32.pt)
  - SHA-256：`a3f163a736c1241fd004d63bcc62c8856a5abce138a0fa893fc728a413c050e3`
- 方案 A 量化配置：
  [`candidate_quant_config.json`](../../model_deployment/baseline_cnn_int8_ptq/candidate_quant_config.json)
  - SHA-256：`ccb1d8f9e14462f00ae2f69c49e7abefab7de94e5f5865c47b20bab9695695e5`
- 纯整数参考：`onn_model.int8_reference.Int8Reference`
- 数据集：官方 MNIST 测试集全部 10,000 张，固定顺序且不打乱。

评测入口会从配置文件读取并强制使用冻结的 activation scale 和 weight scale；
权重、bias 及 requant 参数均未重新标定。

## 输入处理

三种条件均遵循相同顺序：原始灰度图 → `ToTensor`（范围 `[0,1]`）→ 分辨率变换
→ `Normalize(mean=0.1307, std=0.3081)` → 冻结模型。

| 条件 | 处理方式 |
|---|---|
| `native_28` | 保持原始 28×28 |
| `down8_up28` | area 下采样至 8×8，再以 nearest 放大至 28×28 |
| `down4_up28` | area 下采样至 4×4，再以 nearest 放大至 28×28 |

样例对比见 [`sample_comparison.png`](sample_comparison.png)。

## 主要观察

1. `native_28` 复现了冻结部署链路的基准水平，三条路径准确率相差不超过
   0.02 个百分点，整数/fake 预测一致率为 99.91%。
2. 直接降到 8×8 有效分辨率后，纯整数准确率降至 31.37%，相对基准下降
   67.10 个百分点；类别差异明显，数字 0 仍为 98.06%，而数字 3 和 6 接近失效。
3. 4×4 条件下纯整数准确率仅 10.45%，接近随机猜测。10,000 张样本中有 9,049 张
   被预测为 0、942 张被预测为 9，说明输出发生严重类别塌缩。
4. `down4_up28` 的整数/FP32 一致率仍有 96.89%，但两者准确率都很低；因此高路径
   一致率只说明量化实现行为接近，不能被解释为模型质量良好。
5. 当前冻结 BaselineCNN 对 8×8 和 4×4 有效输入均不具备可接受的直接兼容性。
   若这些分辨率是后续系统目标，需要重新训练或进行分辨率感知训练/标定，而这超出
   本实验的冻结条件。

## 科学边界

本实验只是在理想数字域中执行 area 下采样和 nearest 放大，验证固定数字模型对空间
信息损失的敏感性。它不包含光电突触阵列的器件非线性、噪声、响应不一致、动态范围、
时序采样、光学串扰或接口误差。因此，理想数字 4×4/8×8 结果**不等于**真实器件响应，
也不能替代真实阵列、硬件在环或测试集级 FPGA 输入链路验证。
