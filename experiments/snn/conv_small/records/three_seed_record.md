## 每个 IF 每张图片平均 fire 次数

直接由已保存的最终测试发放总数计算，未重新推理或评价测试准确率。
统计一张图片完整 24 个时间步，分母包括所有 IF（包括不发放的 IF）：

```text
平均 fire 次数 / IF / 张 = 该层在 10,000 张图片上的发放总数 / (10,000 × 该层 IF 数)
```

第一层有 16×8×8=1,024 个 IF，第二层有 32×4×4=512 个 IF。
每个通道的每个空间位置对应一个 IF 神经元；读出无阈值发放，故不纳入统计，器件输入也不算隐藏 IF。

| seed | 第一层 fire/IF/张 | 第二层 fire/IF/张 | 全部隐藏 IF fire/IF/张 |
|---|---:|---:|---:|
| 7 | 0.4220 | 4.7044 | 1.8495 |
| 17 | 0.4289 | 5.2746 | 2.0442 |
| 27 | 0.3913 | 4.3142 | 1.6990 |
| **三个 seed 均值** | **0.4141** | **4.7644** | **1.8642** |

- 第一层平均每个 IF 每张图片 fire **0.4141 次**，平均占 24 步的 **1.73%**。
- 第二层平均每个 IF 每张图片 fire **4.7644 次**，平均占 24 步的 **19.85%**。
- 全部 1,536 个隐藏 IF 的加权平均为 **1.8642 次/IF/张**；按 IF 数加权，
  不是将两层均值各取一半。

这些是层内所有神经元及图片的平均值，不能解释为每个具体 IF 都发放相同次数。
不足 1 次表示平均值，不表示神经元可发放分数次；当前 IF 每步最多发放一次，完整 24 步最多 24 次。
现有记录未保留每个具体 IF 的发放分布，不能仅凭平均数判断哪些 IF 从不发放或频繁发放。
原始总数、逐 seed 结果及计算口径见 [firing_statistics.json](../results/firing_statistics.json)。
